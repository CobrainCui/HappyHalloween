# 南瓜小径 · Pumpkin Hollow

一个万圣节主题的像素风网页横版小游戏原型。大部分线路是单角色；「百鬼夜行」里玩家用同一套方向键同时操控整支百鬼队伍，「鬼鬼祟祟」则是两名玩家共用一副键盘的双人同屏潜行。灵感来自《森林冰火人》：走路、跳跃、收集骨头，并在电磁场里调节速度穿过熔岩。

当前版本是 **0.9 原型**：

- **新手教程**：鼓励式引导、无失败、可随时跳过；一条练习小径上依次教走路、跳跃与 `↓` 穿过木板、拾取骨头和时装零件、糖果带来的身体状态、把地上的南瓜推着走 / 抱起来抛 / 叠高翻墙，最后按 `Tab` 认识背包、衣橱和糖果罐。跳过教程会直接进入追思小径。
- **追思小径**：主面板保留的正式线路「五盏灯」，五段路，每段对应一位曾经来访的人；段与段之间用墓园门连接。
- **百鬼夜行**：另一条独立的万圣夜正式线路，六段夜路，从山道一路走到钟楼顶的百鬼门。玩家是提灯人，用一套方向键同时带着越走越长的同行者队伍（最终 11 个身体）；每个身体的重力、跳跃、水性和能力都不同，南瓜鸟居只认「所有同行者都到齐」。三条赛道（提灯夜路 / 雾中长街 / 无灯长夜）共用这六段地标，但长度、落脚点和走散的代价不同；困难赛道里，每一次有人被瘴气击中都要亲手留下一名同行者。
- **鬼鬼祟祟**：一条独立的两名玩家同屏潜行线路。鬼鬼用 `A / D / W / S`，祟祟用方向键；南瓜各抱各的——鬼鬼按 `E`，祟祟按 `/`。五段后院夜路，从翻过后院、守夜人的灯，到晾糖场的秤门、画像长廊和屋顶上的烟花。没有背包、骨头与电磁场。
- **会动的南瓜**：所有线路——教程、五盏灯（含地下的电磁长夜）、百鬼夜行、鬼鬼祟祟——地上的南瓜都是实体。走上去会把它推走，按 `E` 抱起、再按 `E` 抛出；抛到另一颗南瓜顶上就会叠高。叠好的南瓜可以踩上去，够到一个人跳不过去的高度。第一段路中间就有一堵这样的高墙。
- **电磁长夜 · 终章**：原先独立的「电磁长夜」不再从主面板单独进入，整条电子大厅 + 两口熔岩井现在是追思小径第五段的最后一程。
- **万圣节行囊**：路上散落着骨头、时装零件和糖果。零件可以拼成三套时装；糖果捡到就会吃下，让角色短暂进入一种与真实诊断同名的状态。百鬼夜行不使用这套行囊。
- 不做传统关卡切换；整段流程在同一张连续地图里，垂直方向也有镜头跟随。

## 启动

需要 Node.js 18+（仅用于本地静态服务器，没有第三方依赖）。

```bash
npm start
```

浏览器打开 <http://127.0.0.1:4173>。

游戏铺满整个窗口（16:9 画面居中，其余留夜色），不再显示页头与页脚。从起始页开始任何一条线路时会自动进入浏览器全屏；`F` 随时切换全屏，`Esc` 也能退出全屏。

> 项目使用 ES Modules，直接双击 `index.html` 会被浏览器的文件协议拦截，请通过本地服务器访问。

调试时可以在地址后加 `?debug`，游戏实例会暴露为 `window.__pumpkinGame`。

## 操作

| 按键 | 动作 |
| --- | --- |
| `←` / `→` | 左右行走 |
| `↑` | 跳跃（按住跳得更高） |
| `↓` | 地面下蹲 / 空中快速下落 / 穿过木板 |
| 场内 `←` / `→` | 向左 / 向右推进；允许反向，平衡速度需要向右 |
| `E` | 与铜球、骨槽互动；抱起 / 抛出南瓜；百鬼夜行里敲响石鼓请同行者加入（鬼鬼祟祟里祟祟改用 `/`） |
| `Tab` | 打开 / 关闭背包；在骨槽旁可放置骨头；百鬼夜行里打开「百鬼名册」 |
| `1` – `4` | 在骨槽的背包界面里选择要放入的骨头 |
| 鼠标点击 | 在背包的「万圣节衣橱」里穿上 / 换下时装 |
| `Esc` / `P` | 暂停 / 继续；名册打开时关闭名册 |
| `R` | 重新开始本段；百鬼夜行只回到这一段的起点，之前加入的同行者还在（困难赛道里已经留下的名字不会回来） |
| `M` | 开关音效 |
| `F` | 全屏 / 退出全屏；开始任何一条线路时也会自动进入全屏 |
| 双击 `←` / `→`（百鬼夜行狼人同行时） | 全队向前冲刺一小段；蝙蝠也在队里时，可以在二段跳后于空中冲刺 |
| 贴墙再按 `↑`（百鬼夜行黑猫同行时） | 全队从墙上蹬出去，不消耗二段跳次数 |
| 困难赛道被冲散后 `1` – `9` | 从名册上选择要留下的同行者（也可以直接点卡片） |
| 鬼鬼：`A` / `D` / `W` / `S`；祟祟：`←` / `→` / `↑` / `↓` | 「鬼鬼祟祟」双人同屏：分别控制两只小鬼；按住下键潜行 |
| 鬼鬼 `E`；祟祟 `/` | 「鬼鬼祟祟」里各自抱起 / 抛出南瓜：谁按的谁动手 |
| `Space`（谁都能按） | 收紧两只鬼之间的影子线：站稳的人当桩，把对方拉过来或吊住 |

> 百鬼夜行没有额外的移动键：`←` / `→` / `↑` / `↓` 同时作用于队伍里的每一个身体。走得慢的科学怪人、跳得高的床单幽灵、水里快的沼泽怪、能二段跳的蝙蝠、会绷带兜底的木乃伊、能双击冲刺的狼人、两只骷髅、会滑翔的女巫和会蹬墙的黑猫，共用同一双脚。
>
> 鬼鬼祟祟是唯一一条两名玩家共用一台电脑的线路：左手机械键盘的 `A / D / W / S` 给鬼鬼，右手方向键给祟祟。两个人都走到门口才算过关；任何一个人被灯照到，两只鬼会一起退回影子记号。跳到对方头顶上可以叠起来，按住 `Space` 可以收紧两人之间的影子线。互动键也是分开的：鬼鬼按 `E`、祟祟按 `/`，抱起南瓜再按同一个键抛出，不会因为另一个人离南瓜更近就替对方动手。

## 玩家面板

画面右上角常驻显示，右上角的按钮可以把面板折叠成两种更小的形态：

- **完整**：当前进度、主题，以及这一局的所有细节。
- **简省信息版**：只留主题、进度条和一两条关键数字（追思小径是病人与灯，百鬼夜行是同行者与门，鬼鬼祟祟是暴露度）。
- **开关**：整块面板收成一枚「旅人手记」按钮，点一下重新展开。

完整形态按线路显示：

- 当前进度、主题
- 骨头收集总数、剩余右手骨数量
- 糖果收集数量
- 当前生效的糖果状态（疾病名、诊断编码、剩余秒数）
- 当前穿着的时装
- 游戏时间
- 当前电荷 `q = +1 / -1 / 0`
- 皮鞋合脚度（仅追思小径）

皮鞋是追思小径的暗线：新鞋会偏硬，随着行走距离逐渐合脚。合脚度只提供很小的移动手感加成。进入场景时有一道短促的亮光扫过，并在脚边留下鞋头反光。教程、百鬼夜行和鬼鬼祟祟都不设皮鞋，面板、背包和结算里也不会出现合脚度。

## 完整流程：电磁长夜

> 「电磁长夜」不再从主面板单独进入；它现在完整地作为追思小径第五段的赛道出现。以下内容同样适用于第五段，只是入口顺序接在四段墓园夜路之后。

### 1. 起始厅：正电与负电

两颗铜球分别提供 `+1` 和 `-1` 电荷。靠近后按 `E` 选择；再次按 `E` 可释放电荷。经过时可跳过，但后方熔岩场没有电荷就无法悬浮。

### 2. 孤立电子大厅

大厅中段被一条深裂隙截断，不能再贴着地面从下方溜过去。裂隙的死亡判定在平台下方一段距离，失足后还有一点挽回空间。

- **下层路线**：四块窄平台，间隔 80px。普通跳跃跳不过去；不带电无法通过。坑底悬浮的电子会排斥负电荷，负电荷借推力延长跳跃，才能逐块落到下一块平台。
- **上层路线**：第一段是 48px 落差，超过普通跳跃高度，需要上方那颗电子吸引正电荷；之后的台阶都是普通 32px，正电荷上去后可以正常攀爬。同一颗电子会把负电荷压回下层。

两条路线在右侧加宽的骨槽台汇合。平台加宽后，靠近骨槽和速度选择器的位置已经完全离开电子场，不会再被推向右边的熔岩。正负电荷都能通过，但自然路线不同：正电荷走上层，负电荷走下层；负电荷在上层失手时会掉回下层或裂隙。掉进裂隙会回到裂隙前的落脚点，电荷保留。

汇合后的骨槽台左侧立着与起始厅相同的第二对铜球（正电 / 负电），就在换磁场的骨槽旁边。玩家在进入第一口井前可以在这里重新选一次电荷，或者按 `E` 把电荷释放掉。

大厅里的电子分布在不同高度，场半径和强度也各不相同。每颗电子中央画一个**减号**，表示它带负电；不再绘制电场线和箭头，避免画面过于杂乱：

- 正电荷：被电子吸引。
- 负电荷：被电子排斥。

HUD 的「合力」箭头由所有电子的场矢量叠加得出，显示的是当前实际受力方向，而不只是最近那颗电子。高处平台和额外骨头是可选的探索路线；两条主路线沿途都放了骨头。

### 3. 两口熔岩井

逆流井之后直接就是终点岛，原先更远处的第三口井（骨火井）已经移除。

每口井前都有一个骨槽。场区按真实洛伦兹力 `F = q(E + v × B)` 决定轨迹：

1. 在骨槽旁按 `Tab` 打开背包。
2. 从背包里选择一件东西放进凹槽。
3. 右手骨会按右手定则对齐磁场方向，使 E 与 B 的力可以互相抵消；放普通骨头只会被骨槽吐出来，而且不会消耗。
4. 带着电荷踏入场区，用「← / →」左右推进，把速度维持在 HUD 显示的平衡速度 `v = E / B` 附近，越过熔岩。速度可以反向；只有向右的速度能让 E 与 B 的力抵消。
5. 场区高度是原版的三倍，镜头会随垂直移动。
6. 井顶封着一排倒挂尖刺：场没对齐、人被托向井顶时会撞上尖刺并被送回落脚点，不能从上方绕过熔岩。

平衡速度只由 `E / B` 决定，与电荷正负无关；但速度偏离平衡时，正负电荷受到的竖直回复力方向相反。骨槽没有对齐时，E 与 B 不再抵消，合力方向同时取决于你的电荷和 B 的朝向：可能把你压向熔岩，也可能把你托向井顶。HUD 的「场力」一栏显示的就是当前实际受力的竖直方向。

每一口井前都有独立骨槽；对齐磁场是稳定通过的正途。场景里有大量普通骨头作为干扰，也散布着额外的右手骨；左手骨更少，主要用来拼骷髅。

第一口井和第二口井之间的安全岛上还有第三对铜球（骨槽 B 右侧）。跨过沉降井后可以先在这里换一次电荷，再进逆流井。逆流井是最后一口井，对岸就是光门。

## 追思小径：五盏灯（正式线路）

起始页的「追思小径」是主面板保留的正式线路。玩家是一个心理世家的子弟；万圣节傍晚，ta 提着五盏小灯去墓园，为逝去的病人和家族前辈点灯。去墓园的路被五扇门分成五段，每段路会想起一位曾经来访的人。这五个人不是医生，而是在精密测量、系统、天文观测、高原科考、档案研究里各自走到很远的亲历者——病没有挡住他们，只是长期跟着他们。

前四段是地面上的墓园夜路；第五段沉入地下，直接沿用整条「电磁长夜」赛道——电子大厅、深裂隙、两口熔岩井和速度选择器都在这里，背包与右手骨也重新可用。主面板不再单独提供电磁长夜入口。

前四段刻意做得简单：地面连续、没有岩浆与深坑，只有几级矮石阶和可选的单向木板。真正的阻力来自这一段的记忆——玩家会短暂带上那位病人可被观察到的行为特点。前四段以 5 秒为周期触发：第一段是一整套南瓜车检查任务，其余三段仍是一小段短暂的身体反应。第五段是电磁长夜，停住之间的间隔拉长到 11–16 秒，给玩家留出跳过裂隙、平台和熔岩井的窗口；发作时仍可能在半空被定住。

第一段是例外：主角乘着南瓜车驶到墓园外，车停稳、人下车之后才开始被玩家操控。此后每 5 秒会冒出一句「我要回去看看南瓜车锁没锁」，屏幕左上方同时出现任务条和 10 秒倒计时。走回南瓜车旁按 `E` 检查车锁，任务结束，再继续往前走；如果 10 秒内没回去，整个画面开始红色报警闪烁，角色会抓狂地不停自动跳，但左右移动等操控仍然有效，直到回去检查为止。

第一段也是五段里最长的一段：从南瓜车到第一扇门有 122 格（约 1856px），比其余几段长一倍多。以最高移速算，从南瓜车出发 15 秒也只能走出约 1560px——也就是「清掉一次任务后，下一次 10 秒倒计时一定会先烧完」。所以无论玩家怎么折返检查，最后一段路都必须在红色报警、身体不停自动跳的状态下走完。这是第一段刻意留下的难点：不是躲开它，而是带着它继续走。路中间还有一堵 4 格高的石墙，一个人跳不过去；墙前放了三颗南瓜，要推一颗到墙边、抱起另一颗抛上去叠高，再踩着南瓜翻过去。南瓜在教程里有完整教学，前四段都能推、抛、叠。

每段的天色也属于那个人：每段的天空、远山和雾都取自该病种对应的颜色（第一段青灰、第二段赭黄、第三段夜蓝、第四段紫褐、第五段灰蓝），整个画面再轻轻压一层同色光。第五段换成洞穴后，石柱、浮尘和雾光仍沿用同一套灰蓝色。走进一段，先认出颜色，再认出人。

| 段落 | 路上的人 | 诊断（ICD-10） | 这一段的「身体反应」 |
| --- | --- | --- | --- |
| 第一段 | 小满（精密测量） | 强迫性障碍（F42） | 每 5 秒想回去看南瓜车锁没锁；任务倒计时 10 秒，超时后整屏报警、角色不停跳。路最长，中途一堵 4 格高墙要把南瓜叠高才能翻过去；最后一段必然在报警里走完 |
| 第二段 | 林老师（系统） | 广泛性焦虑障碍（F41.1） | 移速略慢；每隔 5 秒没来由地惊跳、后退一下 |
| 第三段 | 许奶奶（天文观测） | 非器质性失眠症（F51.0） | 移速略慢；每隔 5 秒走神一小会儿，画面暗下去，像短暂的微睡眠 |
| 第四段 | 阿岚（高原气象） | 惊恐障碍（F41.0） | 每隔 5 秒突然定住约 1.2 秒，四周收窄成隧道视野，再慢慢打开 |
| 第五段 | 周叔（档案） | 恶劣心境（F34.1） | 电磁长夜赛道：电子大厅、深裂隙、两口熔岩井；移速降到 70%、跳跃变低；每隔 11–16 秒停住约 1.2 秒；画面持续褪色，偶尔短暂回暖 |

规则与叙事：

- 每段路中央有一个淡淡的人影和一截蜡烛。走到跟前会自动点亮，并浮出那个人的一句话。段尾是一扇墓园门，穿过门就进入下一段；前四段结束不会结算，第五段尽头才结算。
- 第五段还会经过家里人的墓，点起第六盏灯。第五段的周叔记忆在赛道入口，家里人的墓在终点岛上。结算界面会显示「点亮的记忆」和「走过的段落」。
- 第五段对应持续性抑郁障碍（恶劣心境）：画面会逐渐去饱和，偶尔短暂恢复一点暖色，再褪回去——这是慢性、难根治，而不是一次性治愈。
- 段与段之间保留游戏时间、点过的灯和皮鞋的磨损；按 `R` 只回到本段起点，之前段落的灯不会灭。
- 这里的名称和编码同样来自现行 ICD-10 分类，只借用可观察到的行为做玩法，不描述、不评判真实的患病体验，也不构成诊断。它想表现的是一小段陪伴，而不是把病做成难关。
- 前四段不需要背包：没有骨头、糖果和时装，`Tab` 会提示「手里只有灯」。第五段进入电磁长夜后，背包、右手骨、骨槽和场区重新可用，也重新有骨头、糖果和时装零件可捡。
- 五段对应 `background.md` 主线采用的五个病种（强迫症、广泛性焦虑、失眠、惊恐、持续性抑郁）。环性心境在设定中列为第 6 段候选（轻躁与低落的轻微正弦起伏），当前「五盏灯」未启用，留作可选隐藏段。

## 百鬼夜行（正式线路）

起始页的第三条正式线路，和「电磁长夜」「五盏灯」的背景完全无关，但仍然发生在万圣夜，是一条自己的万圣夜队伍夜话。完整的背景、角色与关卡设计见 [`parade.md`](./parade.md)。

万圣节的晚上，雾见镇的南瓜灯一盏盏亮起来。子夜的第十三声钟敲过之后，镇上所有化装成鬼怪的孩子、屋檐下所有被刻成笑脸的影子，一起排成一支没有尽头的队伍——今年的百鬼夜行，要从山道一直走到钟楼顶的百鬼门。提灯的孩子提着祖传的南瓜灯笼走在最前面。灯一旦点亮就不能放下：它照到哪里，鬼就跟到哪里；提灯人停下，队伍就会忘记自己要去哪儿。

于是玩家成了整支队伍的头：**一套方向键，所有同行者一起响应**。你走多快，身后的鬼就走多快；你跳，所有鬼一起跳。每经过一座石鼓，按 `E` 就有一位客人决定跟上队伍。到百鬼门前时一个都不能少，否则镇上的灯会在午夜一起熄灭。

这条线路不使用行囊系统（骨头、糖果状态、时装或电荷）；路边的糖桶只是装饰，但南瓜灯和地上的南瓜都能推、抱、抛、叠，整支队伍会一起把它们挤开。`Tab` 打开的是「百鬼名册」，列出当前同行者和还没遇到的客人。队伍的名册、特质与这一段的进度都在右上角玩家面板里。

**核心规则**

- 六段夜路从山道一路走到钟楼：山道、雾町、雨川、废寺、墓园、钟楼。每段开场带着之前所有同行者，路上再请新的客人；队伍从 1 人长到 11 人。
- 开局先选一条赛道。**提灯夜路**就是原来的六段夜路；**雾中长街**在每段插进 10 格额外夜路、抽掉一半落脚点、水流更急；**无灯长夜**每段插进 20 格、只留三分之一的落脚点，并且每一次有人被瘴气击中都要从名册上亲手留下一名同行者；留下的角色，其队伍支援也会失效。提灯童子不能留下，只剩他一人时本局结束。
- 每个身体有自己的重力、跳跃高度、速度、水性和能力。同一个输入会在不同身体上长出不同轨迹：床单幽灵跳得高、落得慢，会自己落到屋顶上；科学怪人走得慢、落得快；沼泽怪在水里快，能逆流上浮；蝙蝠能在空中再扑腾一次；木乃伊的绷带每个落脚点能单独救回一人；狼人让全队能双击冲刺；女巫按住 `↑` 能借扫帚滑翔；黑猫让全队能贴墙再蹬一次。
- 水里不能从河床起跳：按住 `↑` 划水，贴近水面再按跳才能跃出。雨川和积水里有几样陆地上没有的东西：水面急流会把人往回流、废桥和石梁压在水面下、气泡柱会把站在里面的人托回水面。
- 南瓜鸟居只认「所有同行者都到门」，横向到门、纵向也要在门所在的高度。落在后面的脚会把整支队伍叫住，得往回走把大家拢起来。
- 任何一个同行者碰到瘴气，整支队伍都会回到上一个落脚点重新聚拢，面板里的「被冲散」加一。落脚点也要等最慢的那双脚过了才记录。
- `R` 回到本段起点：之前段落的同行者与统计保留，这一段新请的客人要重新敲石鼓。

**队伍支援与组合技**

同行的客人不是各走各的：每加入一个人，整支队伍都会得到一份被动支援。`Tab` 名册顶部会列出当前生效的支援。

- **科学怪人「开路」**：撞开的裂石整列塌，整条路对所有人打开。
- **床单幽灵「轻风」**：全队下落轻 6%、跳跃初速 +3%。
- **沼泽怪「泡泡护航」**：全队划水 +20%，非沼泽怪的上浮上限也更深。
- **蝙蝠「全队二段跳」**：起跳后松开 `↑`，在空中再按一次 `↑`；整支队伍都能再蹬一次。
- **木乃伊「绷带兜底」**：每个落脚点一次。有人碰到瘴气时，只有他被拉回落脚点，全队不重来，也不计入「被冲散」。困难赛道里，绷带只免回程，免不掉送别。
- **骷髅兄弟「双子步频」**：两只骷髅都在队里时，全队移速 +6%。
- **狼人「双击冲刺」**：在地面上快速双击 `←` / `→`，全队一起向前冲一段，冷却约 1 秒。
- **女巫「全队滑翔」**：下落时按住 `↑`，整支队伍都会借到扫帚的风；女巫自己封顶 46，其他身体封顶 58。
- **黑猫「猫步蹬墙」**：在空中贴着墙再按一次 `↑`，全队都能从墙上蹬出去；墙跳不消耗二段跳次数。
- **组合技「扫帚旋风」**：蝙蝠 + 女巫同时在场。先跳、松开 `↑`、再按 `↑`（全队二段跳），然后按住 `↑`（全队滑翔）——整支队伍可以一起越过钟楼的宽缺口。下层长梯仍然是一条更慢的备用路。
- **组合技「月下连扑」**：狼人 + 蝙蝠同时在场。二段跳之后，在空中快速双击 `←` 或 `→`，全队会向前扑一段，用来补上宽了半格的断口。
- **组合技「九命绷带」**：木乃伊 + 黑猫同时在场。困难赛道里，每段第一次送别时，黑猫会顶替一次，不需要从名册上留下同行者。

**三条赛道**

| 赛道 | 长度 | 落脚点 | 走散的代价 |
| --- | --- | --- | --- |
| 简单 · 提灯夜路 | 原来的六段 | 全部保留 | 全队回到上一个落脚点，重新聚拢 |
| 普通 · 雾中长街 | 每段多 10 格绕行 | 隔一个留一个，最后一段保留 | 同上；水流更急、瘴气更密 |
| 困难 · 无灯长夜 | 每段多 20 格绕行 | 只留三分之一，最后一段保留 | 每次有人被瘴气击中都要亲手从名册上留下一名同行者；提灯童子不能留下，只剩他一人时本局结束 |

额外夜路不是另写的地图，而是在每段的平地上插入一截有瘴气沟、窄木板和裂石壁的夜路，再把后面的地形、装置、水域和落脚点整体右移。所以三条赛道的景物是同一套，路线长度不同。

困难赛道里被留下的角色会带走自己的队伍支援。唯一的例外是科学怪人：他离开后，剩下的队伍还能一起推塌裂石，但要贴住石壁顶 0.8–2.4 秒，人越多越快。

**难度曲线**

- 第一段只有两个身体，地形平缓：教「所有同行者都要到门」和「科学怪人能撞开别人撞不开的石壁」，唯一会死的地方是一格宽断口和一截木桥。
- 第二段把队伍拆成上下两层：床单幽灵自然会被风托上屋顶木板，科学怪人和提灯童子落到雾巷。两组人最后必须重新并拢，玩家要学会同时照看两个高度。
- 第三段把同一个输入放进水里：水里没有河床起跳，只能按住 `↑` 划水、贴着水面跃出。水面急流会把人往回流，废桥把河面压成一条只能潜水通过的桥洞，气泡柱则能快速把人托回水面。它第一次让「身体不同」变成路线和介质差异，而不是单纯的跳跃高度差。
- 第四段加到 6 个身体：蝙蝠加入后，全队获得二段跳（起跳后松开 `↑`，在空中再按一次 `↑`）；木乃伊加入后，每个落脚点有一次绷带兜底。废寺积水里要潜水钻过石梁，出口的瘴气沟只留一条窄木板，七级石阶上又加了一面只认科学怪人的裂石壁。队伍人数和地形都比第三段更紧。
- 第五段加到 9 个身体：墓园把高空木板路、地面瘴气坑、墓穴积水、三面裂石壁和长阶串在一起。床单幽灵可以走屋顶的捷径，两只骷髅凑齐后全队还会提速，狼人让全队能双击冲刺；其余脚要在低处把瘴气和石头一一处理掉。
- 第六段加到 11 个身体：钟楼是一条向上的长路。底层水井、盘旋石阶、宽缺口、缺口下的水潭与下层长梯、最后的塔阶和瘴气沟叠在一起。女巫加入后全队获得滑翔，黑猫让全队能贴墙再蹬一次；和蝙蝠的二段跳连起来就是「扫帚旋风」：先跳、松开 `↑`、再按 `↑`，然后按住 `↑`，整支队伍一起越过宽缺口。下层长梯是更慢但更稳的备用路。

美术上，每一段有自己的天色（暗红山道、雾蓝屋顶、雨青河岸、赤红废寺、紫绿墓园、深蓝钟楼），共用红月、南瓜灯、鸟居、纸灯笼、石灯笼、竹丛、鬼火、糖桶和瘴气紫雾。雨川一段会落雨；水里会压上一层深蓝色的水下色、冒出细碎气泡，入水和跃出都有水花，气泡柱则是一整道从河底升到水面的亮泡。

## 地上的南瓜：推、抛、叠

所有线路里的南瓜都不再只是装饰，而是有碰撞盒、会落地的实体：教程、五盏灯的前四段、第五段的电磁长夜洞穴、百鬼夜行的六段夜路（路边的南瓜灯也算），以及鬼鬼祟祟的屋顶赛道。

- **推**：走到南瓜旁边，身体会把它顶开；推到石墙或另一颗南瓜跟前时，自己也会停下来。
- **抱与抛**：靠近时按 `E` 抱起来，南瓜会跟在你头顶；再按 `E` 抛出。手里没南瓜时，`E` 仍然优先处理铜球、骨槽、南瓜车和石鼓，只有附近没有装置时才会抱南瓜。鬼鬼祟祟里两个人的互动键分开：鬼鬼按 `E`，祟祟按 `/`。
- **多名玩家**：鬼鬼祟祟里两个小鬼都能推、抱、抛，每人最多抱一颗，各用各的互动键（鬼鬼 `E`、祟祟 `/`），谁按的谁动手。百鬼夜行里整支队伍都会把南瓜挤开，但只有提灯人按 `E` 抱南瓜。
- **叠高**：抛起时如果正前方近处有另一颗南瓜，会朝它顶上轻轻落下；叠好后可以直接踩上去。两颗南瓜叠起来有 24px 高，再跳一次就能翻过一个人跳不过去的 4 格石墙。
- **会塌**：把下面那颗推走，上面的南瓜会自己掉下来；并排的南瓜互相推不动，得绕到另一侧推或者抱起来。
- **掉进坑里会回来**：南瓜滚进深坑或岩浆后，会回到最初摆放的位置，不会被永久弄丢。
- 教程会在第 5、6 步教推和抛，第 7 步用一堵 4 格高墙教叠高翻墙（墙前三颗南瓜，两颗就能叠出台阶）；第一段路中间的高墙旁也有三颗南瓜，走近时会提示一次怎么叠。南瓜放错位置也不会卡死：抱起来再抛一次就好，摔不坏。

## 万圣节行囊：零件、时装与糖果

路上的发光拾取物分三类：骨头、时装零件、糖果。背包里除了原有的骨槽面板，还多了「糖果罐」和「万圣节衣橱」。

三套时装按零件数量区分收集难度，零件本身又分「常见 / 少见 / 稀有」三档：

| 时装 | 零件数 | 零件 | 说明 |
| --- | --- | --- | --- |
| 阿飘（假扮鬼） | 2 | 旧床单（常见）、黑布眼洞（少见） | 最容易凑齐，罩上就不像人了 |
| 骷髅 | 4 | 头骨（常见）、肋骨（常见）、腿骨（常见）、左手骨（少见） | 用路上的骨头拼成，不额外消耗右手骨 |
| 南瓜巫师 | 5 | 破尖帽（稀有）、星纹斗篷（稀有）、南瓜魔杖（稀有）、咒语书（少见）、假胡子（少见） | 零件分散在上层、下层、落脚点和井内，最费事 |

零件不会全铺在地上：

- 常见零件放在地面或矮台上；少见零件浮在需要起跳的高台边缘；稀有零件藏在窄平台之间的裂隙上方，或直接悬浮在熔岩井里，要靠正确的电荷和平衡速度才够得到。
- 右手骨是消耗品，比左手骨多得多：正式旅程里有 10 根右手骨、4 根左手骨。左手骨只用来拼骷髅，右手骨还要留给两口井的骨槽。
- 教程里的肋骨放在第一块矮木板上，头骨和左手骨分别放在矮骨台和台阶上，顺手教一次起跳与按住 `↓` 从木板下穿；四件零件刚好在教程末尾拼出骷髅。

规则：

- 收集记录只增不减：每种零件只要本局捡到过一次就永久记为已见。右手骨放进骨槽会消耗库存，但不会影响时装的收集进度。
- 集齐后自动换上；在背包的「万圣节衣橱」里可以随时换下或换穿。
- 正式旅程里每种零件都至少出现两次，错过一个还能在别处找到；教程只放糖果和骨头，头骨、肋骨、腿骨和左手骨刚好能在教程末尾凑出骷髅。
- 糖果数量仍然克制：教程只放 1 颗，正式旅程放 10 颗（十种各一颗），分散在地面、平台间隙和熔岩井里。捡到就会吃下，不需要按键使用。

### 糖果：临时的心理状态

十种糖分别对应十种真实存在的诊断名（ICD-10 中文正式名称），只借用该诊断里可观察到的行为表现做玩法。名称没有自造；状态只是游戏机制，不构成诊断，也不代表真实的患病体验。

| 糖果 | 状态（ICD-10） | 持续 | 角色行为 |
| --- | --- | --- | --- |
| 玉米糖 | 躁狂症（F30 躁狂发作） | 10 秒 | 随机自动向上跳，跳高为普通跳跃的 2 倍；跳跃中仍可左右移动 |
| 棒棒糖 | 强迫症（F42 强迫性障碍） | 10 秒 | 每次起跳落地后，自动补跳一次（约 3/4 高度） |
| 巧克力 | 抑郁障碍（F32 抑郁发作） | 10 秒 | 精神运动性迟滞：移速降到 62%、跳跃高度降到约 70%，身子更沉、下落更快 |
| 酸味软糖 | 惊恐障碍（F41.0 惊恐障碍） | 8 秒 | 每隔几秒不受控地向前冲刺并惊跳，冲刺瞬间免疫危险 |
| 甘草糖 | 注意缺陷多动障碍（F90 多动性障碍） | 10 秒 | 移速提升 45%、摩擦变小；每隔几秒走神约 0.3 秒，左右输入失效 |
| 棉花糖 | 妄想性障碍（F22） | 8 秒 | 飞行妄想：按住 ↑ 直接升空，松开缓慢下沉，← → 照常移动；飞行时场也拉不住你 |
| 跳跳糖 | 抽动障碍（F95） | 8 秒 | 每隔一秒左右不自主地抖一下：短促上弹，并随机向一侧偏 |
| 太妃糖 | 双相情感障碍（F31） | 12 秒 | 每 3 秒在高涨（移速 ×1.5、跳跃更高）与低落（移速 ×0.55、跳跃更低）之间切换 |
| 薄荷糖 | 发作性睡病（G47.4） | 10 秒 | 每隔几秒睡着约 1 秒，期间左右和跳跃都不听使唤，身体顺着惯性下坠 |
| 牛轧糖 | 对立违抗障碍（F91.3） | 8 秒 | ← 和 → 的效果对调，想往右走必须按左键 |

教程里第一次遇到糖果时，教程提示语是：「陌生人给的糖，小朋友不能乱吃。可惜我是大学生。」

叠加规则：

- 不同糖果可以同时生效，数值按乘法叠加，行为各自触发；角色身上会同时出现几圈不同颜色的光。
- 同一种糖果再吃一颗，持续时间累加（上限为单颗时长的 2 倍）。
- 终点岛上的巧克力和甘草糖离得很近，可以连着吃下，观察两种状态叠加；第一口和第二口井里也各藏了一颗糖。
- Tab 背包里，糖果种类图鉴放在最下方，排在衣橱之后。

## 鬼鬼祟祟：双人同屏潜行（独立线路）

这是与教程、追思小径、电磁长夜都没有关系的一条独立赛道。两名玩家共用一台电脑、一副键盘，操控两只偷溜出门的小鬼：**鬼鬼**（青蓝）和**祟祟**（暖黄），去南瓜大宅的屋顶看万圣节烟花。

### 故事线

万圣夜的雾见镇，家家门口都点着南瓜灯。午夜钟响时，南瓜大宅的屋顶会放一场烟花——全镇的孩子都知道，只有鬼不行。鬼鬼和祟祟从篱笆底下钻进去，想在第十三声钟响前一声不响地爬上屋顶：

1. **翻过后院**：后门锁着，两块旧石板还认鬼的脚步声。
2. **守夜人的灯**：老守夜人提着南瓜灯在墓碑之间巡夜；灯照到的地方，鬼就会显出轮廓。
3. **晾糖场**：厨房把给全镇孩子准备的糖挂在晾架上；糖仓的门锁在一杆只认重量的老秤上。
4. **画像长廊**：画像里的眼睛会跟着灯转；去年舞会踩塌的地板上，只铺得开一条影子桥。
5. **屋顶上的烟花**：老守夜人正在屋顶上摆今年的烟花。两只鬼要在他转身之前，溜到屋脊上去。

第十三声钟响时，他朝空荡荡的屋脊看了一眼，像是早就知道那儿坐着谁。

| 玩家 | 移动 | 跳 | 潜行 | 互动（抱 / 抛南瓜） | 影子线 |
| --- | --- | --- | --- | --- | --- |
| 鬼鬼 | `A` / `D` | `W` | 按住 `S` | `E` | 谁都能按 `Space` |
| 祟祟 | `←` / `→` | `↑` | 按住 `↓` | `/` | 谁都能按 `Space` |

- 两个人都走到门口才算过关；任何一个人被守夜人照到，两只鬼会一起退回上一个「影子记号」。
- 按住潜行键会走得很慢，但身体变淡、灯照不到；墓碑与屋檐下的影子区则完全安全。
- 石板门：站上石板就能压开对应的铁门。有些门需要两块石板「同时」有人；有些门只认「任意一块」，于是要轮流替对方把门压住。**南瓜也能当砝码**：推一颗到秤盘上，门会一直认它的重量，两个人就都能腾出手来过门。铁门上方有一层一直顶到夜空的透明符障，叠罗汉也翻不过去——门只能靠石板打开。也有几扇门顶上留了缝：踩着南瓜或叠罗汉翻过去，再用影子线把同伴拉过来。
- 影子桥：和石板门同理，桥只在有人（或一颗南瓜）压住石板时存在。压住石板的人一松脚，桥就会散。
- 后三段的地图比一屏高：晾糖架、画像长廊和屋顶会把镜头往上带，两个人在不同高度时镜头会尽量同时框住他们。
- 后三段有的守夜人会**提着灯来回走**。灯光锥跟着转身，院子里的影子会一段一段地换位置；等他背过去，或者蹲低屏住呼吸。
- 这一条线没有背包、骨头、糖果和电磁场，`Tab` 只会在手里摸到一胆子。
- 路上也有可推、可抱、可叠的南瓜：两个小鬼都能碰，但互动键分开——鬼鬼按 `E`、祟祟按 `/`，谁按的谁抱起或抛出，不会替对方动手；叠起来的南瓜同样可以当台阶。

### 叠罗汉、影子线与组合技

两只鬼之间总有一根很淡的影子线。除了各自走跳，它们还能把对方当成台阶和绳子：

- **叠罗汉**：跳到对方头顶上就会站住。头顶的人跟着下面的人一起走、一起跳；按自己的跳跃键可以从头顶弹开，走出头顶的范围就会掉下去。
- **蓄力弹跳**：下面的人按住潜行键蹲下，头顶的人再跳——这一下会弹得比普通跳高得多，用来翻过一个人绝对翻不过去的墙。
- **拉线 / 收线**：按住 `Space` 绷紧影子线。站稳的那个人当桩，线太远时不会硬拽；靠近之后线会自动往回收，把另一个人拖过来。
- **拉一把**：一个人站在高墙或高台上，另一个人被吊到墙沿下面时，线会替他把腿抬上去，直接站到同一层。翻过一个人跳不上去的墙，除了叠罗汉+蓄力弹跳和南瓜台阶，这也是第三条路。
- **拉过门**：有几扇铁门顶上留了缝（第一段、晾糖场和屋顶那段的露台各有一扇）。一个人踩着南瓜（或叠罗汉）翻过去以后，门这边的人贴到门边，另一个人按住 `Space` 收线——线会把他整个从门那边拽过来。
- **吊住**：有人踩空往黑水沟里掉时，站在岸边的人按住 `Space`，就能把他吊在半空，等桥铺好再放开。

线够不着时按 `Space` 不会有任何拉扯，所以原本需要两个人分开站石板的门不会被这根线破坏；只有顶上留了缝的门，能靠影子线把同伴拽到门的另一边。

五段由易到难；后三段都留了不止一条通关路线：

| 段落 | 名字 | 教什么 / 有哪几条路 |
| --- | --- | --- |
| 第一段 | 翻过后院 | 两个人各站一块石板，一起打开第一扇门；旁边有一块可以试着叠罗汉的旧木板。石板凑不齐时，也可以踩着南瓜翻过门，再用影子线把同伴拉过来。 |
| 第二段 | 守夜人的灯 | 第一次遇到灯：蹲下潜行，学会在影子里等灯转过去。 |
| 第三段 | 晾糖场 | 秤盘、南瓜砝码和一条晒糖长绳。地面路线用两杆秤盘换着压门、跳黑水沟、躲开提着灯来回走的守夜人；上层路线要先踩着同伴的肩爬上晾架，再顺着长绳从整段路上方走过去，尽头那扇门也可以直接叠罗汉翻过去。 |
| 第四段 | 画像长廊 | 同时压住两块秤盘打开第一道门；塌掉的舞厅地板只铺得开一条影子桥，也可以从长凳爬上旧画框，沿上层画廊跳过缺口。下面有两盏来回走的灯，上面没有灯但路更窄。 |
| 第五段 | 屋顶上的烟花 | 最后一程：烟囱墙要先叠罗汉+蓄力弹跳（再用影子线把人吊上来），或者用南瓜叠台阶；屋檐可以绕过院子里的灯和影子桥；台上台下两块秤盘才能打开露台的门；最后一级级跳上屋顶，在守夜人的灯背后蹲着溜到屋脊。两个人都到屋顶高度才算数。 |

结算会记下整条赛道的时间、被发现次数和失足次数。

## HUD 与可视化

- 靠近电子时，静态 HUD 显示「合力」箭头；它由所有电子按矢量叠加，正电荷被电子吸引，负电荷被电子排斥。
- 场区 HUD 显示 E / B 的大小与方向、当前场力的竖直方向、平衡速度、当前速度（带正负方向）与左右推进提示。
- 速度选择器的匀强电场以**长线 + 箭头**绘制，箭头沿 E 的方向流动；孤立电子不画电场线，只用光晕和中央减号。
- 磁场以 `⊗ 纸内 / ⊙ 纸外` 的符号网格显示。
- 井顶尖刺与裂隙都有独立的危险提示；所有骨头共用同一种骨色，只有形状和名字不同。
- 所有非岩浆地面都铺着不能拾取的细小白骨，作为场景氛围；可拾取物会发光、漂浮，并在拾取时显示提示。骨头共用暖白色；时装零件按稀有度发光，常见偏淡紫、少见偏青蓝、稀有偏金橙；糖果按种类各自发光。具体种类靠形状和名字区分。
- 吃到糖果后，角色身上会出现对应颜色的光晕，面板里列出所有生效状态与剩余时间；同种糖叠加时时间会累积。
- 双相情感障碍会在状态条上标出当前是「高涨」还是「低落」；发作性睡病睡着时头顶会冒 Z；飞行妄想状态下按住 ↑ 可以直接升空。

## 关键可调参数

- `src/config.js`：重力、跳跃、移动速度等基础手感；`FIELD` 块里的像素/米换算、电荷加速度系数与介质阻力；`ELECTRON.maxAcceleration` 限制电子核心附近的强度。
- `src/level.js`：地图、场区高度（当前 552px）、E/B 数值、骨槽与拾取物；`getFieldAcceleration()` 是 `F = q(E + v × B)` 的唯一实现，`getElectronAcceleration()` 负责所有电子的矢量叠加。
- `src/player.js` 的 `updateHover()`：把洛伦兹力积分进玩家轨迹，并叠加介质阻力；`applyElectricForce()` 使用统一的电子场合力。
- `src/game.js` 的 `getFieldStatus()`：HUD 实时提示（场力方向也来自同一套洛伦兹力计算）；电子合力也在这里汇总给 HUD。
- 场区的 `e.mag / b.mag` 比值决定平衡速度。
- `src/candyEffects.js`：每种糖果的持续时间、移动/跳跃修正和自动行为触发间隔；`src/game.js` 的 `updateCandyTimers()` / `updateCandyActions()` 负责结算。
- `src/pumpkins.js`：南瓜的尺寸、重力、摩擦、抛起初速度（`PUMPKIN`）都在文件顶部；`resolvePlayer()` 负责推与踩踏，`findStackTarget()` 决定抛起时会不会对准另一颗南瓜叠上去，`pickPlayer()` 是没指定角色时的兜底（鬼鬼祟祟里通常由 `game.interact(actor)` 直接指定鬼鬼或祟祟）；掉出地图的南瓜会回到 `homeX/homeY`。`src/level.js` 会把 `decorations` 里所有 `type: 'pumpkin'` 的摆放点抽成 `pumpkinSpawns`，由 `src/game.js` 在每次 `loadTheme()` 时重建 `PumpkinWorld`；普通线路每帧传入 `game.members`，鬼鬼祟祟在 `src/sneakMode.js` 的 `updateSneak()` 里传入两个小鬼。
- `src/parade.js`：百鬼夜行的六段章节（`PARADE_CHAPTERS`）、三条赛道（`PARADE_TRACKS`：额外夜路格数、落脚点密度、水流倍率、走散规则）、每段的天色与开场白、开场就有的同行者（`party`）、新客人（`joins`），以及 `YOKAI` 图鉴里每个身体的 `traits` / `teamLabel` 和 `PARADE_COMBOS`。想改科学怪人的速度、床单幽灵的重力、沼泽怪的游泳强度、蝙蝠的二段跳、木乃伊的绷带兜底、狼人的双击冲刺、女巫的滑翔、黑猫的蹬墙，先动这里。
- `src/level.js` 的 `buildParadeOne()`～`buildParadeSix()`：六张基础地图的格子、裂石（`C`）、水域（`waterZones` 的 `currentX` / `surfaceCurrentX`）、气泡柱（`updrafts`）、瘴气、石鼓（`device.type: 'mask'` 的 `yokaiIds`）、落脚点与 `goalY`。`applyParadeTrack()` 会在 `PARADE_ANNEX_AT` 指定的平地上插入额外夜路；想调整三条赛道的长度，改 `PARADE_TRACKS[].annex` 与 `PARADE_ANNEX_AT` / `PARADE_GROUND_ROW`。`goalY` 是终点南瓜鸟居所在的高度，用来防止有人从下层走到门柱下方也被算作到门。
- `src/game.js` 的 `setupParadeParty()` / `addParadeMember()` 负责队伍建立与请人；`rebuildPartySupport()` 把同伴的本事分给全队，`getParadeSupports()` 给名册提供队伍支援列表；`isMemberAtGate()` / `paradeGateCount()` 是所有到门的判定；`updateParadeHazards()` 负责全员冲散、木乃伊的绷带兜底与困难赛道的送别；`openSacrifice()` / `chooseSacrifice()` 是困难赛道的名册减员；`registerCrackPush()` / `updateTeamSmash()` 负责科学怪人被留下后「全队一起顶裂石」的弱化版本；`advanceParade()` 负责段与段之间保留队伍、赛道与已留下的名字。多身体共用按键时，`Input.fork()` 会给每个同行者一份各自的「刚按下」事件，避免第一个人把跳跃键吃掉。
- `src/player.js` 的 `traits` 读取：`moveScale`、`jumpScale`、`gravityScale`、`maxFallScale`、`waterMoveScale`、`swim`、`extraJumps`、`glide`、`smash`；`teamSupport` 读取队伍支援（全队二段跳、滑翔、划水、提速、轻风、双击冲刺、空中冲刺、蹬墙跳、绷带兜底、九命绷带）。`getWaterAt()` 的水流、水面急流、划水与水面跃出，以及 `getUpdraftAt()` 的气泡托举都在 `update()` 里结算，入水/出水通过 `onWaterEnter` / `onWaterExit` 交给 `src/game.js` 生成水花和声音；`breakColumn()` 在 `moveHorizontal()` 里触发。
- `src/sneak.js`：五段赛道的名字、故事线、开场白、目标，以及每段的地图格、石板门（`mode: 'all' | 'any'`、`latch`、`climbable`）、影子桥、守夜人（`range`、`halfAngle`、`sweep`、`speed`，以及来回走用的 `patrol` / `patrolSpeed`）、影子区、地图高度（`height` / `groundRow`）与教学提示。`src/sneakLevel.js` 负责把这些数据变成实际地图；铁门上方一直顶到夜空的透明符障是 'g' 格，实心但不画门，开门时和门一起消失——`climbable: true` 的门（第一段、晾糖场、屋顶的露台门）不铺符障，顶上留一道缝。`src/sneakMode.js` 的 `updateExposure()` 决定暴露快慢，`watcherSees()` 决定灯能不能看见某个人，`updateWatchers()` 让巡逻的守夜人转身，`updateGates()` 负责石板门与影子桥（人和南瓜都能压住秤盘），`updateStack()` 负责踩在头顶上的叠罗汉与蓄力弹跳，`updateRope()` 负责影子线的收紧、吊住、把人拉上高台，以及隔着 `climbable` 的门把同伴拽过去。想让第一段更简单，先调 `SNEAK_STAGES[0].spec`。
- `src/memorial.js`：五段追思路线的诊断、记忆台词、连续修正、背景病色（`backdrop`）与触发间隔；第一段的南瓜车检查（`trigger.kind: 'carriage'`）也在这里调任务文本、5 秒频率和 10 秒倒计时。`src/level.js` 的 `MEMORIAL_STAGE_SPECS` 是前四段的简单地图；`buildMerged(5)` 负责把整条电磁长夜作为第五段，并把周叔与家里人的记忆点放进去。`src/game.js` 的 `updateMemorialTimers()` / `updateMemorialActions()` 负责定时行为，`updateCarriageIntro()` / `updateCarriageTimers()` / `updateCarriageAlarm()` / `checkCarriage()` 负责第一段的下车演出、任务与抓狂，`advanceMemorial()` 负责门与门之间的推进。

## 后续方向

- 继续扩展地宫长度和更多非均匀场、纯磁场偏转机关。
- 增加更多时装与零件图鉴；糖果状态的行为参数集中在 `src/candyEffects.js`，方便继续调平衡。
- 将教程与真实流程之间的转场做得更完整。
- 百鬼夜行还可以加更多「身体」：会缩成一团滚过窄缝的、能贴着墙走的、必须和另一只鬼手拉手才过桥的。系统按任意数量设计，`party` 和 `YOKAI` 里加一条就能试。
- 鬼鬼祟祟还可以继续加守夜人行为（听觉、突然转身、不同速度的巡逻）和更多双人机关；五段赛道的格子、石板门、影子桥、高台与提示都集中在 `src/sneak.js`。叠罗汉与影子线的数值（`STACK_FEET`、`STACK_BOOST`、`ROPE.attach`、`ROPE.reel`）都在 `src/sneakMode.js` 顶部。
- 如果要做双人协作，可以让第二位角色携带相反电荷。
