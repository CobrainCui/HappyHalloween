# 南瓜小径 · Pumpkin Hollow

一个万圣节主题的像素风网页横版小游戏原型。大部分线路是单角色；「魑魅魍魉」里玩家用同一套方向键同时操控整支百鬼队伍；「给老师送南瓜派」的第三段是两名玩家共用一副键盘的双人同屏潜行。灵感来自《森林冰火人》：走路、跳跃、收集骨头，并在电磁场里调节速度穿过熔岩。

当前版本是 **0.9 原型**：

- **新手教程**：鼓励式引导、无失败、可随时跳过；一条练习小径上依次教走路、跳跃与 `↓` 穿过木板、拾取骨头和时装零件、糖果带来的身体状态、把地上的南瓜推着走 / 抱起来抛 / 叠高翻墙，最后按 `Tab` 认识背包、衣橱和糖果罐。跳过教程会直接进入「给老师送南瓜派」。
- **给老师送南瓜派（Sir loved pumpkin pie）**：主面板保留的正式线路，四段夜路。玩家提着一盒南瓜派去墓园看老师（`background.md` 里的师祖）；路上每段会想起一位曾经被老师点过灯的人，段与段之间用墓园门连接。第二段是阿岚的集合庭院加惊恐呼吸，第三段是阿遥的双人潜行，第四段是周叔地下室的简易电磁赛道加旧灯负重，路的尽头是老师的墓。完整的电磁长夜搬到了糖纸街副本里，成为男巫的任务。
- **魑魅魍魉**：另一条独立的万圣夜正式线路，六段夜路，从山道一路走到钟楼顶的百鬼门。玩家是提灯人，用一套方向键同时带着越走越长的同行者队伍（最终 11 个身体）；每个身体的重力、跳跃、水性和能力都不同，南瓜鸟居只认「所有同行者都到齐」。三条赛道（提灯夜路 / 雾中长街 / 无灯长夜）共用这六段地标，但长度、落脚点和走散的代价不同；困难赛道里，每一次有人被瘴气击中都要亲手留下一名同行者。
- **Trick or Treat（副本）**：一条没有危险的糖纸街，十户人家各住着一位万圣夜人物。敲门后可以「帮忙」做这一户的任务，拿那一颗固定的增益糖；不想做任务就「捣蛋」，抢过糖钻进屋后的巷子，跑到街尾才拿得到这一户自己的那颗糖。女巫的任务是一座只有一道石门的集合庭院；男巫的任务是从「给老师送南瓜派」搬来的电磁长夜。其余八户各守一扇不同的门：找规律、脑筋急转弯、万圣知识问答、翻牌配对、找不同、天平推理、真假话，以及狼人的屋顶追月闯关。街尾随时可以走，没拿完也没关系。
- **会动的南瓜**：所有线路——教程、给老师送南瓜派（含第二段的集合庭院、第三段的双人潜行与第四段的电磁赛道）、魑魅魍魉、糖纸街——地上的南瓜都是实体。走上去会把它推走，按 `E` 抱起、再按 `E` 抛出；抛到另一颗南瓜顶上就会叠高。叠好的南瓜可以踩上去，够到一个人跳不过去的高度。第一段路尽头就有一堵这样的高墙，翻过去就是出口门。
- **电磁长夜 · 搬到糖纸街**：原先的电子大厅 + 两口熔岩井不再属于「给老师送南瓜派」，而是糖纸街男巫「奥兹」的地窖任务。本线路第四段只留下简化过的铜球与电子场；集合庭院只剩第二段一座，女巫「莫尔」的庭院沿用同一套规则，只留一道门。
- **万圣节行囊**：路上散落着骨头、时装零件和糖果。零件可以拼成三套时装；糖果捡到就会吃下，让角色短暂进入一种与真实诊断同名的状态。魑魅魍魉不使用这套行囊；Trick or Treat 的糖袋是另一套，按 `Q` 全线路可用。
- 不做传统关卡切换；整段流程在同一张连续地图里，垂直方向也有镜头跟随。

## 启动

需要 Node.js 18+（仅用于本地静态服务器，没有第三方依赖）。

```bash
npm start
```

浏览器打开 <http://127.0.0.1:4173>。

游戏铺满整个窗口（16:9 画面居中，其余留夜色），不再显示页头与页脚。从起始页开始任何一条线路时会自动进入浏览器全屏；`F` 随时切换全屏，`Esc` 也能退出全屏。

> 项目使用 ES Modules，直接双击 `index.html` 会被浏览器的文件协议拦截，请通过本地服务器访问。

调试时可以在地址后加 `?debug`，游戏实例会暴露为 `window.__pumpkinGame`。

### 手机 / 平板试玩

手机横屏打开同一个地址即可。页面会收起页头页脚，只留 16:9 画面，并在画面底部叠上虚拟按键：

- 左下角 `←` `→` 移动，`↓` 下蹲 / 空中快速下落 / 穿过木板
- 右下角 `↑` 跳跃，`互动` 抱南瓜、敲石鼓、与铜球和骨槽互动
- 底部中间 `背包` / `糖袋` / `暂停`；暂停面板里可以直接「重走这一段」
- 竖屏打开时会提示把设备横过来，横屏后自动继续

在电脑浏览器里想预览移动端布局，可以在地址后加 `?mobile=1`。

「给老师送南瓜派」第三段是双人同屏潜行：电脑端两名玩家共用一副键盘（你 `WASD`、回音方向键）。手机端没有第二套方向键，这一段会让回音自动跟着你走，一个人也能走完；其余段落照常。手机端不显示键盘提示，教程里的按键说明也改成了通用的「互动」「打开背包」。

局域网真机测试：

```bash
npm run start:lan
```

启动后终端会打印同一 Wi-Fi 下的手机访问地址。默认的 `npm start` 仍然只监听 `127.0.0.1`，不会暴露到局域网。

## 操作

| 按键 | 动作 |
| --- | --- |
| `←` / `→` | 左右行走 |
| `↑` | 跳跃（按住跳得更高） |
| `↓` | 地面下蹲 / 空中快速下落 / 穿过木板 |
| 场内 `←` / `→` | 向左 / 向右推进；允许反向，平衡速度需要向右 |
| `E` | 与铜球、骨槽互动；抱起 / 抛出南瓜；魑魅魍魉里敲响石鼓请同行者加入（第三段潜行里回音改用 `/`） |
| `Tab` | 打开 / 关闭背包；在骨槽旁可放置骨头；魑魅魍魉里打开「百鬼名册」 |
| `1` – `4` | 在骨槽的背包界面里选择要放入的骨头 |
| 鼠标点击 | 在背包的「万圣节衣橱」里穿上 / 换下时装 |
| `Esc` / `P` | 暂停 / 继续；名册打开时关闭名册 |
| `R` | 重新开始本段；魑魅魍魉只回到这一段的起点，之前加入的同行者还在（困难赛道里已经留下的名字不会回来） |
| `M` | 开关音效 |
| `F` | 全屏 / 退出全屏；开始任何一条线路时也会自动进入全屏 |
| 双击 `←` / `→`（魑魅魍魉狼人同行时） | 全队向前冲刺一小段；蝙蝠也在队里时，可以在二段跳后于空中冲刺 |
| 贴墙再按 `↑`（魑魅魍魉黑猫同行时） | 全队从墙上蹬出去，不消耗二段跳次数 |
| 困难赛道被冲散后 `1` – `9` | 从名册上选择要留下的同行者（也可以直接点卡片） |
| 你：`A` / `D` / `W` / `S`；回音：`←` / `→` / `↑` / `↓` | 「给老师送南瓜派」第三段双人同屏：分别控制你和回音；按住下键潜行 |
| 你 `E`；回音 `/` | 第三段里各自抱起 / 抛出南瓜：谁按的谁动手 |
| `Space`（谁都能按） | 收紧你和回音之间的影子线：站稳的人当桩，把对方拉过来或吊住 |

> 魑魅魍魉没有额外的移动键：`←` / `→` / `↑` / `↓` 同时作用于队伍里的每一个身体。走得慢的科学怪人、跳得高的床单幽灵、水里快的沼泽怪、能二段跳的蝙蝠、会绷带兜底的木乃伊、能双击冲刺的狼人、两只骷髅、会滑翔的女巫和会蹬墙的黑猫，共用同一双脚。
>
> 「给老师送南瓜派」第三段是唯一一段两名玩家共用一台电脑的夜路：左手机械键盘的 `A / D / W / S` 给你，右手方向键给回音。两个人都走到门口才算过关；任何一个人被提灯人照到，两个人会一起退回影子记号。跳到对方头顶上可以叠起来，按住 `Space` 可以收紧两人之间的影子线。互动键也是分开的：你按 `E`、回音按 `/`，抱起南瓜再按同一个键抛出，不会因为另一个人离南瓜更近就替对方动手。手机端没有第二套方向键，回音会自动跟着你走。

## 玩家面板

画面右上角常驻显示，右上角的按钮可以把面板折叠成两种更小的形态：

- **完整**：当前进度、主题，以及这一局的所有细节。
- **简省信息版**：只留主题、进度条和一两条关键数字（给老师送南瓜派是病人与灯，第三段是暴露度，魑魅魍魉是同行者与门）。
- **开关**：整块面板收成一枚「旅人手记」按钮，点一下重新展开。

完整形态按线路显示：

- 当前进度、主题
- 骨头收集总数、剩余右手骨数量
- 糖果收集数量
- 当前生效的糖果状态（疾病名、诊断编码、剩余秒数）
- 当前穿着的时装
- 游戏时间
- 当前电荷 `q = +1 / -1 / 0`
- 皮鞋合脚度（仅给老师送南瓜派）
- 身后的皮鞋名字（仅给老师送南瓜派）

皮鞋是给老师送南瓜派的暗线：新鞋偏硬、不合脚，随着行走距离逐渐顺着脚变形、合脚。它说的话只围绕合脚、磨损和脚感；偶尔提一句「这种磨合算不算学习」，但不给答案。合脚度只提供很小的移动手感加成。进入场景时有一道短促的亮光扫过，并在脚边留下鞋头反光。教程和魑魅魍魉不设皮鞋；第三段只有你穿着鞋，回音没有。

每走过一段，那一段的人的皮鞋会跟在你身后：小满的走两步停半拍，像还在数台阶；阿岚的偶尔屏住一口气，再轻轻跟上；阿遥的总侧着一点，像在听另一双，身后偶尔多出一层很淡的复影；周叔的每一步都沉一点，像脚下还带着水。走过的那些鞋共用你刚走过的那条足迹链，前进速度和主角相同，排在前面的不会超过去，排在后面的也掉不了队。跳跃、坠坑、读档或穿门把距离突然拉开时，鞋群会在你身后重新排队；你站住不动时，它们也收住脚步，顺着落速落到脚下，不会挂在跳跃弧线的中间。面板的「身后」一行只写名字。走完第四段时，周叔那双也最后跟上来，四双鞋一起停在老师的碑前；结算页会记下「身后的皮鞋 4 双」。

## 电磁长夜（糖纸街 · 男巫地窖）

> 「电磁长夜」现在不再属于给老师送南瓜派，而是糖纸街男巫「奥兹」的地窖任务。以下内容同样适用于这个房间；在街上敲奥兹的门、选「帮忙」就能进去。

### 1. 起始厅：正电与负电

两颗铜球分别提供 `+1` 和 `-1` 电荷。靠近后按 `E` 选择；再次按 `E` 可释放电荷。经过时可跳过，但后方熔岩场没有电荷就无法悬浮。

### 2. 孤立电子大厅

大厅中段被一条深裂隙截断，不能再贴着地面从下方溜过去。裂隙的死亡判定在平台下方一段距离，失足后还有一点挽回空间。

- **下层路线**：四块窄平台，间隔 80px。普通跳跃跳不过去；不带电无法通过。坑底悬浮的电子会排斥负电荷，负电荷借推力延长跳跃，才能逐块落到下一块平台。
- **上层路线**：第一段是 48px 落差，超过普通跳跃高度，需要上方那颗电子吸引正电荷；之后的台阶都是普通 32px，正电荷上去后可以正常攀爬。同一颗电子会把负电荷压回下层。

两条路线在右侧加宽的骨槽台汇合。平台加宽后，靠近骨槽和速度选择器的位置已经完全离开电子场，不会再被推向右边的熔岩。正负电荷都能通过，但自然路线不同：正电荷走上层，负电荷走下层；负电荷在上层失手时会掉回下层或裂隙。掉进裂隙会回到裂隙前的落脚点，电荷保留。

汇合后的骨槽台左侧立着与起始厅相同的第二对铜球（正电 / 负电），就在换磁场的骨槽旁边。玩家在进入第一口井前可以在这里重新选一次电荷，或者按 `E` 把电荷释放掉。

大厅里的电子分布在不同高度，场半径和强度也各不相同。每颗电子中央画一个**减号**，表示它带负电；不再绘制电场线和箭头，避免画面过于杂乱：

- 正电荷：被电子吸引。
- 负电荷：被电子排斥。

HUD 的「合力」箭头由所有电子的场矢量叠加得出，显示的是当前实际受力方向，而不只是最近那颗电子。高处平台仍是可选的探索路线，上面放着星纹斗篷和南瓜魔杖；两条主路线不再铺普通骨头。

### 3. 两口熔岩井

逆流井之后直接就是终点岛，原先更远处的第三口井（骨火井）已经移除。

每口井前都有一个骨槽。场区按真实洛伦兹力 `F = q(E + v × B)` 决定轨迹：

1. 在骨槽旁按 `Tab` 打开背包。
2. 从背包里选择一件东西放进凹槽。
3. 右手骨会按右手定则对齐磁场方向，使 E 与 B 的力可以互相抵消；放普通骨头只会被骨槽吐出来，而且不会消耗。
4. 带着电荷踏入场区，用「← / →」左右推进，把速度维持在 HUD 显示的平衡速度 `v = E / B` 附近，越过熔岩。速度可以反向；只有向右的速度能让 E 与 B 的力抵消。
5. 场区高度是原版的三倍，镜头会随垂直移动。
6. 井顶封着一排倒挂尖刺：场没对齐、人被托向井顶时会撞上尖刺并被送回落脚点，不能从上方绕过熔岩。

平衡速度只由 `E / B` 决定，与电荷正负无关；但速度偏离平衡时，正负电荷受到的竖直回复力方向相反。骨槽没有对齐时，E 与 B 不再抵消，合力方向同时取决于你的电荷和 B 的朝向：可能把你压向熔岩，也可能把你托向井顶。HUD 的「场力」一栏显示的就是当前实际受力的竖直方向。

每一口井前都有独立骨槽；对齐磁场是稳定通过的正途。场景里不再铺普通骨头干扰；两口井各要一块右手骨，路上正好放了两块。左手骨只在第二段出现。

第一口井和第二口井之间的安全岛上还有第三对铜球（骨槽 B 右侧）。跨过沉降井后可以先在这里换一次电荷，再进逆流井。逆流井是最后一口井，对岸就是光门。

## 给老师送南瓜派：四盏灯（正式线路）

起始页的「给老师送南瓜派」（Sir loved pumpkin pie）是主面板保留的正式线路。玩家是一个心理世家的当代弟子；万圣节傍晚，ta 提着一盒南瓜派去墓园看老师——就是 `background.md` 里那位心理学先驱、师祖。去墓园的路被三扇门分成四段，每段路会想起一位曾经被老师点过灯的人。这四个人不是医生，而是在精密测量、高原气象、无线电观测和档案研究里各自走到很远的亲历者——病没有挡住他们，只是长期跟着他们。路的尽头是老师的墓，玩家把南瓜派放在碑前；老师生前最爱这一口。

本线路的四段夜路里，第二段有一座集合庭院；第三段是双人同屏的墓园潜行；第四段是一条地下简易电磁赛道，同时带着周叔的负重和旧灯。完整的「电磁长夜」赛道——电子大厅、深裂隙、两口熔岩井和速度选择器——搬到了糖纸街男巫奥兹的地窖；糖纸街女巫莫尔的房间则是一座只有一道石门的集合庭院。主面板不单独提供电磁长夜入口。

本线路四段的共同底子是：真正的阻力来自这一段的记忆——玩家会短暂带上那位病人可被观察到的行为特点。第一段是一整套南瓜车检查任务；第二段是集合庭院加惊恐发作后的呼吸小游戏；第三段是提灯人、影子和另一个自己；第四段是简易电磁赛道，负重随路程加深，停住只落在结实的落脚点上。前两段的地面连续、没有深坑；第三段有一条黑水沟和一条影子桥；第四段有几道裂隙，最后一段还被中间的小岛分成两跳，掉下去只回到上一个落脚点。

第一段是例外：主角乘南瓜车从墓园外慢慢驶入，车停稳、人下车之后才开始被玩家操控。这段车程约 14 秒，车上会用四句独白把这一夜的来由讲完——万圣节、提着一盒南瓜派、路上会经过四个被老师点过灯的人、以及老师那句「记住的是人，不是病名」。第一句独白说完后（约第 4.5 秒）屏幕下方会出现「直接下车」，按 `E` / 点互动可以跳过剩下的车程；看完整段车程后，下车时会提示「第一段路，你想起小满」。此后每 5 秒会冒出一句「我要回去看看南瓜车锁没锁」，屏幕左上方同时出现任务条和 10 秒倒计时。走回南瓜车旁按 `E` 检查车锁，任务结束，再继续往前走；如果 10 秒内没回去，整个画面开始红色报警闪烁，角色会抓狂地不停自动跳，但左右移动等操控仍然有效，直到回去检查为止。按 `R` 重来本段时不会再放一遍开场车程。

第一段很短：从南瓜车到高墙只有约 52 格，翻过墙再走几步就是这一段的出口门。阻力集中在尽头那堵 4 格高的石墙——一个人跳不过去，墙前放了三颗南瓜，要推一颗到墙边、抱起另一颗抛上去叠高，再踩着南瓜翻过去。翻过去之后没有后半段路，门就在墙后。南瓜在教程里有完整教学，前两段都能推、抛、叠。

第二段是阿岚的「集合庭院」。她在高原气象站值冬时靠一本集合论笔记熬过长夜，笔记里没有算式，只有把东西一圈一圈排好的图。庭院里有一组完整的东西——骨头、幽灵、骷髅、眼睛、手、蜡烛；它们不是靠颜色和形状拼出来的，每一颗都只是一个东西。骨头是骷髅的一部分：骷髅属于哪一边，骨头就跟着属于哪一边，成员板上也紧挨着骷髅排列。元素身上不挂标签；门楣左侧挂着一块成员板，图标放大两倍，旁边直接写出名字（如「A 骷髅 骨头 眼睛」「B 幽灵 眼睛」），玩家不用猜图标。格子旁边不放普通南瓜，庭院地面只有门里的元素；普通南瓜只在庭院外的空地上。第二段的两道门：第一道是分格门，地面分成四个边界清楚的格子，每格的牌子上写着这一格认的具体运算——`A − B`、`A ∩ B`、`B − A`、`A ∪ B` 上加一横（两边都不在）；第二道是接龙门：A 里的每样东西都接到它后面的那一样，最后一样接回第一样；门楣只画前两段，剩下的留问号，地面三个小台各立着 A 里的一个元素，玩家把 B 里的东西放到对应的小台下。元素只有放到归属对应的位置才算数，随便放不算。放对了的元素会亮起来；全部分对，整扇石门缓缓沉进地里，门才真正打开。

**注意**：上面这套集合庭院在给老师送南瓜派第二段有一座；糖纸街女巫莫尔的房间沿用同一套规则，只有一道交集门、六颗东西，没有记忆和旧灯。第三段是双人潜行的墓园夜路；第四段不再用集合门，改成下面这条简易电磁赛道。

给老师送南瓜派第二段的惊恐障碍：第一次在 18–24 秒后、之后每 36–50 秒，先有一小段心跳预兆（画面边缘轻轻脉动）。预兆期按 `E` 可以稳住呼吸，直接平复；如果让它发作，视野会从四周向角色收拢，只剩身边一个随心跳一缩一缩的小孔，颜色退掉、上方像被压住。按一下 `E` 或按住不放，呼吸一次，小孔就慢慢退开、世界重新亮起来，并得到 11 秒「定神」——这段时间不会再发作，脚步也略稳。不按也不会卡死，13 秒后呼吸会自己慢下来，只是没有定神奖励。

第二段的两道门考法各不相同，成员板会直接列出 A、B 里有哪些东西：

- **交集 `A ∩ B`**：A = {骷髅, 骨头, 眼睛}，B = {幽灵, 眼睛}；骷髅和幽灵都有眼睛，单独的眼球在两边，进 A∩B；骨头是骷髅的一部分，跟着骷髅进 A−B；幽灵只在 B 里，进 B−A。
- **接龙映射 `A → B`**：A = {骷髅, 幽灵, 蜡烛}，B = {幽灵, 蜡烛, 骷髅}；门楣只画「骷髅→幽灵」「幽灵→蜡烛」两段，最后一段留问号。地上放着幽灵、蜡烛、骷髅，把它们分别放到 A 里对应元素的小台下：骷髅台放幽灵，幽灵台放蜡烛，蜡烛台放骷髅，首尾接成一个圈。

分格门的每格上方立着一块牌子，写的是这一格认的运算，而不是只有一个 A 或 B；接龙门的小台上则立着 A 里对应元素的放大图标和名字。元素放对了会亮起一圈淡光，顶上缓缓升起几点光。门楣左侧的成员板把 A、B 的成员图标放大并写出名字，门身还画着这一门的小格地图；目标格会亮起来。门脚有一排小点，放对一颗亮一颗；所有位置都放对、玩家又在门附近，整扇石门就缓缓沉进地里。格子和台子只是地面标记，不挡路；元素照旧可以推、抱、抛、叠。门锁一次，之后一直开着。没有失败、没有倒计时，也不需要按任何键——看懂门上的两个集合、把东西各归各位就行。第二段两道门解开后显示「石门 2/2」，糖纸街女巫房间一道门显示「石门 1/1」。第三、四段没有集合门：第三段是双人潜行，第四段是电磁赛道。

第三段是阿遥的「另一双脚步」。阿遥在山上守一台老无线电，能听见很远的声音，也听见一些别人听不见的。这一段里，你身边多了一个只有你听得见的「回音」：电脑端两名玩家共用一副键盘，你按 `A / D / W / S`，回音按方向键；手机端回音会自动跟着你走。两个人都走到墓园门口才算过关。提灯人提着灯在墓碑间来回走，按住 `S` / `↓` 潜行，或躲进墓碑的影子，灯就从头顶过去；暴露条被照满，你和回音会一起退回最后一个影子记号。两块石板同时压住，前面的铁门才升起；影子桥只认石板，一个人压住，另一个人先过。南瓜可以推、抱、抛、叠，也能替人压住石板。第三段没有背包，糖袋按 `Q` 仍可用。

给老师送南瓜派第四段是周叔地下室的简易电磁赛道，同时带着他的「负重」。这一段只保留电磁长夜最核心的铜球与电子：入口一对铜球分别给正电和负电；第一道裂隙下方的电子把负电推上去，第二道裂隙上方的电子把正电拉过去；再往后是一条被小岛分成两跳的宽裂隙——第一跳仍是负电，跳上岛后用岛上的铜球换成正电，再跳过第二跳。沿途四对铜球可以随时换电荷。走错电荷不会死，只会掉回上一个落脚点，电荷还留着。没有熔岩井、骨槽、速度选择器和右手骨——那些都留在糖纸街男巫的地窖。走得越深，移动越慢、跳跃越低，画面也越灰；路上四盏旧灯，走到跟前会自动点起，给 9 秒「透亮」——颜色回来、脚步变轻，灯灭之后重量还会回来。每 24–34 秒会有一次「抬不起脚」，但只落在结实的落脚点上；发作时不是定死，按住方向键能一步一步挪出去，移动会明显更快结束。

每段的天色也属于那个人：每段的天空、远山和雾都取自该病种对应的颜色（第一段青灰、第二段紫褐、第三段灰绿、第四段灰蓝），整个画面再轻轻压一层同色光。第四段换成洞穴后，石柱、浮尘和雾光仍沿用同一套灰蓝色。走进一段，先认出颜色，再认出人。

| 段落 | 路上的人 | 诊断（ICD-10） | 这一段的「身体反应」 |
| --- | --- | --- | --- |
| 第一段 | 小满（精密测量） | 强迫性障碍（F42） | 每 5 秒想回去看南瓜车锁没锁；任务倒计时 10 秒，超时后整屏报警、角色不停跳。路很短，尽头一堵 4 格高墙必须把南瓜叠高才能翻过去，翻过墙就是出口门 |
| 第二段 | 阿岚（高原气象） | 惊恐障碍（F41.0） | 心跳预兆后视野从四周收拢到角色身边的小孔；按一下或按住 `E` 呼吸一次，视野慢慢打开，平复后 11 秒不再发作。这一段还有第一座集合庭院：两道门，交集 / 接龙 |
| 第三段 | 阿遥（无线电观测） | 精神分裂症（F20） | 墓园双人潜行：提灯人的灯来回扫，蹲进墓碑影子或按住 `S` / `↓` 潜行；暴露条满了两个人一起退回影子记号。两块石板同时压住开门，影子桥认石板；两个人都到门口才算过关 |

规则与叙事：

- 每段路中央有一个淡淡的人影和一截蜡烛。走到跟前会自动点亮，并浮出那个人的一句话。段尾是一扇墓园门，穿过门就进入下一段；前三段结束不会结算，第四段尽头才结算。穿过最后一道门后先放一幕碑前的长镜头：黑屏里落雪，主角和身后四双皮鞋走到大墓碑前坐下、分南瓜派；随后切黑一秒，换成主角的第一人称，看着自己把派放在碑旁、用刀叉切成小块，皮鞋围着墓碑和吃派的自己蹦跳。这一幕按 `E` / 空格 / 回车或轻触画面可以跳过，播完才进结算。
- 第四段还会经过老师的墓，点起第五盏灯。第四段的周叔记忆在电磁赛道入口，老师的墓在赛道尽头；走到碑前，玩家放下南瓜派。结算界面会显示「点亮的记忆」「走过的段落」和「身后的皮鞋」（走完四段是 4 双）。
- 第四段对应持续性抑郁障碍（恶劣心境）：画面会随着路程去饱和，旧灯能让颜色短暂回来，灯灭后又褪回去——这是慢性、难根治，而不是一次性治愈。
- 段与段之间保留游戏时间、点过的灯和皮鞋的磨损；按 `R` 只回到本段起点，之前段落的灯不会灭。
- 这里的名称和编码同样来自现行 ICD-10 分类，只借用可观察到的行为做玩法，不描述、不评判真实的患病体验，也不构成诊断。它想表现的是一小段陪伴，而不是把病做成难关。
- 前两段和第三段不需要背包：没有骨头、糖果和时装，`Tab` 会提示「手里只有灯」。第四段背包可用；第四段的零件放在电磁赛道沿途，不需要开背包也能捡。骨槽、场区和完整的电磁长夜在糖纸街男巫地窖。增益糖从糖袋里按 `Q` 吃。
- 时装零件分在本线路的四段，每件只放一次：第一段旧床单、假胡子、腿骨；第二段黑布眼洞、头骨、咒语书、左手骨（要二段跳糖）；第四段肋骨、星纹斗篷（弹簧糖）、南瓜魔杖（飞天糖）、破尖帽（冲刺糖）。第三段是潜行段，不放零件。七件不依赖增益糖的零件都能用普通跳跃或正常路线拿到，四件带糖锁的零件在吃到对应糖后也都够得到。糖纸街的两个房间里不再放时装零件。
- 四段采用的四个病种是强迫症、惊恐障碍、精神分裂症、持续性抑郁；其中精神分裂症是第三段新增的，`background.md` 原来的六项候选里没有列入。设定清单里的其它病种（广泛性焦虑、失眠等）仍保留，供其他线路或后续关卡使用。

## 魑魅魍魉（正式线路）

起始页的另一条正式线路，和「电磁长夜」「给老师送南瓜派」的背景完全无关，但仍然发生在万圣夜，是一条自己的万圣夜队伍夜话。完整的背景、角色与关卡设计见 [`parade.md`](./parade.md)。

万圣节的晚上，雾见镇的南瓜灯一盏盏亮起来。子夜的第十三声钟敲过之后，镇上所有化装成鬼怪的孩子、屋檐下所有被刻成笑脸的影子，一起排成一支没有尽头的队伍——今年的魑魅魍魉，要从山道一直走到钟楼顶的百鬼门。提灯的孩子提着祖传的南瓜灯笼走在最前面。灯一旦点亮就不能放下：它照到哪里，鬼就跟到哪里；提灯人停下，队伍就会忘记自己要去哪儿。

于是玩家成了整支队伍的头：**一套方向键，所有同行者一起响应**。你走多快，身后的鬼就走多快；你跳，所有鬼一起跳。每经过一座石鼓，按 `E` 就有一位客人决定跟上队伍。到百鬼门前时一个都不能少，否则镇上的灯会在午夜一起熄灭。

这条线路不使用行囊系统（骨头、糖果状态、时装或电荷）；路边的糖桶只是装饰，但南瓜灯和地上的南瓜都能推、抱、抛、叠，整支队伍会一起把它们挤开。Trick or Treat 的糖袋是例外，按 `Q` 整队共享。`Tab` 打开的是「百鬼名册」，列出当前同行者和还没遇到的客人。队伍的名册、特质与这一段的进度都在右上角玩家面板里。

**核心规则**

- 六段夜路从山道一路走到钟楼：山道、雾町、雨川、废寺、墓园、钟楼。每段开场带着之前所有同行者，路上再请新的客人；队伍从 1 人长到 11 人。
- 开局先选一条赛道。**提灯夜路**就是原来的六段夜路；**雾中长街**在每段插进 10 格额外夜路、抽掉一半落脚点、水流更急；**无灯长夜**每段插进 20 格、只留三分之一的落脚点，并且每一次有人被瘴气击中都要从名册上亲手留下一名同行者；留下的角色，其队伍支援也会失效。提灯童子不能留下，只剩他一人时本局结束。
- 每个身体有自己的重力、跳跃高度、速度、水性和能力。同一个输入会在不同身体上长出不同轨迹：床单幽灵跳得高、落得慢，会自己落到屋顶上；科学怪人走得慢、落得快；沼泽怪在水里快，能逆流上浮；蝙蝠能在空中再扑腾一次；木乃伊的绷带每个落脚点能单独救回一人；狼人让全队能双击冲刺；女巫按住 `↑` 能借扫帚滑翔；黑猫让全队能贴墙再蹬一次。
- 水里不能从河床起跳：按住 `↑` 划水，贴近水面再按跳才能跃出。雨川和积水里有几样陆地上没有的东西：水面急流会把人往回流、废桥和石梁压在水面下、气泡柱会把站在里面的人托回水面。
- 南瓜鸟居只认「所有同行者都到门」，横向到门、纵向也要在门所在的高度。落在后面的脚会把整支队伍叫住，得往回走把大家拢起来。
- 任何一个同行者碰到瘴气，整支队伍都会回到上一个落脚点重新聚拢，面板里的「被冲散」加一。落脚点也要等最慢的那双脚过了才记录。
- `R` 回到本段起点：之前段落的同行者与统计保留，这一段新请的客人要重新敲石鼓。

**队伍支援与组合技**

同行的客人不是各走各的：每加入一个人，整支队伍都会得到一份被动支援。`Tab` 名册顶部会列出当前生效的支援。

- **科学怪人「开路」**：撞开的裂石整列塌，整条路对所有人打开。
- **床单幽灵「轻风」**：全队下落轻 6%、跳跃初速 +3%。
- **沼泽怪「泡泡护航」**：全队划水 +20%，非沼泽怪的上浮上限也更深。
- **蝙蝠「全队二段跳」**：起跳后松开 `↑`，在空中再按一次 `↑`；整支队伍都能再蹬一次。
- **木乃伊「绷带兜底」**：每个落脚点一次。有人碰到瘴气时，只有他被拉回落脚点，全队不重来，也不计入「被冲散」。困难赛道里，绷带只免回程，免不掉送别。
- **骷髅兄弟「双子步频」**：两只骷髅都在队里时，全队移速 +6%。
- **狼人「双击冲刺」**：在地面上快速双击 `←` / `→`，全队一起向前冲一段，冷却约 1 秒。
- **女巫「全队滑翔」**：下落时按住 `↑`，整支队伍都会借到扫帚的风；女巫自己封顶 46，其他身体封顶 58。
- **黑猫「猫步蹬墙」**：在空中贴着墙再按一次 `↑`，全队都能从墙上蹬出去；墙跳不消耗二段跳次数。
- **组合技「扫帚旋风」**：蝙蝠 + 女巫同时在场。先跳、松开 `↑`、再按 `↑`（全队二段跳），然后按住 `↑`（全队滑翔）——整支队伍可以一起越过钟楼的宽缺口。下层长梯仍然是一条更慢的备用路。
- **组合技「月下连扑」**：狼人 + 蝙蝠同时在场。二段跳之后，在空中快速双击 `←` 或 `→`，全队会向前扑一段，用来补上宽了半格的断口。
- **组合技「九命绷带」**：木乃伊 + 黑猫同时在场。困难赛道里，每段第一次送别时，黑猫会顶替一次，不需要从名册上留下同行者。

| 赛道 | 长度 | 落脚点 | 走散的代价 |
| --- | --- | --- | --- |
| 简单 · 提灯夜路 | 原来的六段 | 全部保留 | 全队回到上一个落脚点，重新聚拢 |
| 普通 · 雾中长街 | 每段多 10 格绕行 | 隔一个留一个，最后一段保留 | 同上；水流更急、瘴气更密 |

额外夜路不是另写的地图，而是在每段的平地上插入一截有瘴气沟、窄木板和裂石壁的夜路，再把后面的地形、装置、水域和落脚点整体右移。所以三条赛道的景物是同一套，路线长度不同。

困难赛道里被留下的角色会带走自己的队伍支援。唯一的例外是科学怪人：他离开后，剩下的队伍还能一起推塌裂石，但要贴住石壁顶 0.8–2.4 秒，人越多越快。

**难度曲线**

- 第一段只有两个身体，地形平缓：教「所有同行者都要到门」和「科学怪人能撞开别人撞不开的石壁」，唯一会死的地方是一格宽断口和一截木桥。
- 第二段把队伍拆成上下两层：床单幽灵自然会被风托上屋顶木板，科学怪人和提灯童子落到雾巷。两组人最后必须重新并拢，玩家要学会同时照看两个高度。
- 第三段把同一个输入放进水里：水里没有河床起跳，只能按住 `↑` 划水、贴着水面跃出。水面急流会把人往回流，废桥把河面压成一条只能潜水通过的桥洞，气泡柱则能快速把人托回水面。它第一次让「身体不同」变成路线和介质差异，而不是单纯的跳跃高度差。
- 第四段加到 6 个身体：蝙蝠加入后，全队获得二段跳（起跳后松开 `↑`，在空中再按一次 `↑`）；木乃伊加入后，每个落脚点有一次绷带兜底。废寺积水里要潜水钻过石梁，出口的瘴气沟只留一条窄木板，七级石阶上又加了一面只认科学怪人的裂石壁。队伍人数和地形都比第三段更紧。
- 第五段加到 9 个身体：墓园把高空木板路、地面瘴气坑、墓穴积水、三面裂石壁和长阶串在一起。床单幽灵可以走屋顶的捷径，两只骷髅凑齐后全队还会提速，狼人让全队能双击冲刺；其余脚要在低处把瘴气和石头一一处理掉。
- 第六段加到 11 个身体：钟楼是一条向上的长路。底层水井、盘旋石阶、宽缺口、缺口下的水潭与下层长梯、最后的塔阶和瘴气沟叠在一起。女巫加入后全队获得滑翔，黑猫让全队能贴墙再蹬一次；和蝙蝠的二段跳连起来就是「扫帚旋风」：先跳、松开 `↑`、再按 `↑`，然后按住 `↑`，整支队伍一起越过宽缺口。下层长梯是更慢但更稳的备用路。

美术上，每一段有自己的天色（暗红山道、雾蓝屋顶、雨青河岸、赤红废寺、紫绿墓园、深蓝钟楼），共用红月、南瓜灯、鸟居、纸灯笼、石灯笼、竹丛、鬼火、糖桶和瘴气紫雾。雨川一段会落雨；水里会压上一层深蓝色的水下色、冒出细碎气泡，入水和跃出都有水花，气泡柱则是一整道从河底升到水面的亮泡。

## 地上的南瓜：推、抛、叠

所有线路里的南瓜都不再只是装饰，而是有碰撞盒、会落地的实体：教程、四盏灯的四段夜路（含第三段的双人潜行）、糖纸街和男巫地窖，以及魑魅魍魉的六段夜路（路边的南瓜灯也算）。

- **推**：走到南瓜旁边，身体会把它顶开。并排贴在一起的几颗会被一起推走，像推一排木箱，推力顺着队伍往后传；直到队尾那颗顶到石墙或另一颗南瓜，自己才会停下来。
- **抱与抛**：靠近时按 `E` 抱起来，南瓜会跟在你头顶；再按 `E` 抛出。手里没南瓜时，`E` 仍然优先处理铜球、骨槽、南瓜车和石鼓，只有附近没有装置时才会抱南瓜。第三段里两个人的互动键分开：你按 `E`，回音按 `/`。
- **多名玩家**：第三段里两个人都能推、抱、抛，每人最多抱一颗，各用各的互动键（你 `E`、回音 `/`），谁按的谁动手。魑魅魍魉里整支队伍都会把南瓜挤开，但只有提灯人按 `E` 抱南瓜。
- **叠高**：抛起时如果正前方近处有另一颗南瓜，会朝它顶上轻轻落下；叠好后可以直接踩上去。两颗南瓜叠起来有 24px 高，再跳一次就能翻过一个人跳不过去的 4 格石墙。
- **会塌**：把下面那颗推走，上面的南瓜会自己掉下来。上下叠着的两颗不算「一排」，推下面那颗不会把上面的端走。
- **掉进坑里会回来**：南瓜滚进深坑或岩浆后，会回到最初摆放的位置，不会被永久弄丢。
- 教程会在第 5、6 步教推和抛，第 7 步用一堵 4 格高墙教叠高翻墙（墙前三颗南瓜，两颗就能叠出台阶）；第一段尽头的高墙旁也有三颗南瓜，走近时会提示一次怎么叠。南瓜放错位置也不会卡死：抱起来再抛一次就好，摔不坏。

## 万圣节行囊：零件、时装与糖果

追思路线上的发光拾取物现在只有时装零件；心理疾病糖不再作为路上的拾取物出现。教程仍留一颗做教学，Trick or Treat 的增益糖进糖袋，按 `Q` 吃。骨槽必需的右手骨留在糖纸街男巫地窖。背包里除了原有的骨槽面板，还多了「糖果罐」和「万圣节衣橱」。

三套时装按零件数量区分收集难度，零件本身又分「常见 / 少见 / 稀有」三档：

| 时装 | 零件数 | 零件 | 说明 |
| --- | --- | --- | --- |
| 阿飘（假扮鬼） | 2 | 旧床单（常见）、黑布眼洞（少见） | 最容易凑齐，罩上就不像人了 |
| 骷髅 | 4 | 头骨（常见）、肋骨（常见）、腿骨（常见）、左手骨（少见） | 用路上的骨头拼成，不额外消耗右手骨 |
| 南瓜巫师 | 5 | 破尖帽（稀有）、星纹斗篷（稀有）、南瓜魔杖（稀有）、咒语书（少见）、假胡子（少见） | 件数最多，分在四段；三件稀有零件都要对应增益糖 |

零件不会全铺在地上，而是均匀分在四个板块，且每件只放一次：

- **第一段**：旧床单在高墙顶上；假胡子、腿骨在单向木板上方，先跳上木板再普通跳一下就能拿到。
- **第二段**：黑布眼洞、头骨、咒语书分别在第一座庭院三道石门后的矮石台上，普通跳一下就能够到；左手骨最刁，必须带着**二段跳糖**。
- **第四段**：肋骨、破尖帽在电磁赛道的地面上方，普通跳一下就能够到；星纹斗篷要**弹簧糖**、南瓜魔杖要**飞天糖**。
- 第三段是潜行段，不放零件。
- 被糖光锁住的零件会显示一把小锁，靠近时会提示还差哪一种糖；没吃对应增益糖时只能看、拿不走。
- 前两段和第三段没有背包，捡到零件会直接记进衣橱；第四段打开背包就能换穿。
- 糖纸街的两个房间不再放时装零件；男巫地窖保留两块右手骨（起始厅一块、岛 B 一块），刚好够开两口井的骨槽。
- 教程里的肋骨、头骨、左手骨和腿骨仍保留，顺手教一次起跳与按住 `↓` 从木板下穿；四件零件刚好在教程末尾拼出骷髅。
- 收集记录只增不减：每种零件只要本局捡到过一次就永久记为已见。右手骨放进骨槽会消耗库存，但不影响时装的收集进度。
- 集齐后自动换上；在背包的「万圣节衣橱」里可以随时换下或换穿。

### 糖果：临时的心理状态

十种糖分别对应十种真实存在的诊断名（ICD-10 中文正式名称），只借用该诊断里可观察到的行为表现做玩法。名称没有自造；状态只是游戏机制，不构成诊断，也不代表真实的患病体验。

| 糖果 | 状态（ICD-10） | 持续 | 角色行为 |
| --- | --- | --- | --- |
| 玉米糖 | 躁狂症（F30 躁狂发作） | 10 秒 | 随机自动向上跳，跳高为普通跳跃的 2 倍；跳跃中仍可左右移动 |
| 棒棒糖 | 强迫症（F42 强迫性障碍） | 10 秒 | 每次起跳落地后，自动补跳一次（约 3/4 高度） |
| 巧克力 | 抑郁障碍（F32 抑郁发作） | 10 秒 | 精神运动性迟滞：移速降到 62%、跳跃高度降到约 70%，身子更沉、下落更快 |
| 酸味软糖 | 惊恐障碍（F41.0 惊恐障碍） | 8 秒 | 每隔几秒不受控地向前冲刺并惊跳，冲刺瞬间免疫危险 |
| 甘草糖 | 注意缺陷多动障碍（F90 多动性障碍） | 10 秒 | 移速提升 45%、摩擦变小；每隔几秒走神约 0.3 秒，左右输入失效 |
| 棉花糖 | 妄想性障碍（F22） | 8 秒 | 飞行妄想：按住 ↑ 直接升空，松开缓慢下沉，← → 照常移动；飞行时场也拉不住你 |
| 跳跳糖 | 抽动障碍（F95） | 8 秒 | 每隔一秒左右不自主地抖一下：短促上弹，并随机向一侧偏 |
| 太妃糖 | 双相情感障碍（F31） | 12 秒 | 每 3 秒在高涨（移速 ×1.5、跳跃更高）与低落（移速 ×0.55、跳跃更低）之间切换 |
| 薄荷糖 | 发作性睡病（G47.4） | 10 秒 | 每隔几秒睡着约 1 秒，期间左右和跳跃都不听使唤，身体顺着惯性下坠 |
| 牛轧糖 | 对立违抗障碍（F91.3） | 8 秒 | ← 和 → 的效果对调，想往右走必须按左键 |

教程里第一次遇到糖果时，教程提示语是：「陌生人给的糖，小朋友不能乱吃。可惜我是大学生。」

### 糖纸街：Trick or Treat 与糖袋

「Trick or Treat」是主面板上的第五个入口，一个约 2–3 分钟的独立副本。它**不产出上面的心理状态糖纸**，只产出十种普通的增益糖；这些糖没有诊断名、没有编码，也不借用任何症状。

**怎么拿到糖**

- 一条没有危险的糖纸街，十户人家各住着一位万圣夜人物。走到门前按 `E`，门会打开，人物和你说话。
- **帮忙**：接下这一户的任务。房间任务直接进屋；街上的门上谜题或屋顶闯关留在街上做。做完任务，这一户固定的增益糖落进糖袋。
- **捣蛋**：抢过这一户的糖就跑，钻进糖纸街屋后的「后巷」。这是一条纯竞速赛道：跑到街尾的栅门、没被这一户的人追上，拿到的一定是这一户自己的那颗糖；被追上，糖被拿回去，这一户留到下一趟。没有随机，也没有换糖。
- 街尾的出口**永远开着**。没拿完、没敲过的门、没做完的任务都可以留在身后；结算会分别记下帮过几户、捣过几次蛋、路过几户。
- 房间任务（女巫的集合庭院、男巫的电磁长夜）里有一扇后门，随时可以回街上，任务进度不保留。同一趟可以反复进出，直到做完。
- 任务可以放弃：换一户敲门、接另一个任务，或者直接走到街尾离开。下一趟再来拿漏掉的固定糖。

| 户 | 人物 | 任务 | 固定的糖 |
| --- | --- | --- | --- |
| 1 | 女巫「莫尔」 | 集合庭院：一道交集门，六颗东西 | 磁力糖 |
| 2 | 男巫「奥兹」 | 电磁长夜：穿过电子厅和两口熔岩井，走到地窖最深处 | 飞天糖 |
| 3 | 骷髅「阿骨」 | 骨牌上的数：看三排骨阵，接上最后一堆 | 弹簧糖 |
| 4 | 床单幽灵「小飘」 | 床单上的三个问题：三道脑筋急转弯 | 羽毛糖 |
| 5 | 狼人「阿嚎」 | 追月亮：月亮落山前按顺序踩过屋顶上的五个记号 | 冲刺糖 |
| 6 | 木乃伊「阿绷」 | 绷带下的图案：翻开十六张牌，配出八对图案 | 月亮糖 |
| 7 | 科学怪人「阿壮」 | 四道万圣题：万圣节知识问答 | 二段跳糖 |
| 8 | 黑猫「煤球」 | 两扇窗：在右窗里找出四处不同 | 蹬墙糖 |

| 10 | 吸血鬼「德古」 | 三只箱子：每轮只有一句真话，找出糖在哪只箱子 | 护身糖 |

男巫的电磁长夜是从给老师送南瓜派搬过来的整条赛道；集合庭院在给老师送南瓜派第二段保留一座，第三段换成双人潜行，第四段留简化的铜球 + 电子场赛道，女巫莫尔的房间只有一道门。

**糖纸街的八扇门**

后八户不再搬南瓜，每户是一扇不同的门。走到门前按 `E`，门板会变成题面：

- **阿骨 · 骨牌上的数**：三排骨阵找规律。选项里的「根」是骨头数；答错会提示先看相邻两堆怎么变。
- **小飘 · 床单上的三个问题**：三道脑筋急转弯。答对一道，窗子亮一盏。
- **阿嚎 · 追月亮**：从街面跳上五级屋顶，月牙记号要按 1→5 的顺序踩。每级抬高两格，落脚点只有两格宽；掉回街面或 20 秒内没踩完，记号重来。
- **阿绷 · 绷带下的图案**：4×4 翻牌，八对图案，翻开两张一样的就松开一截绷带。
- **阿壮 · 四道万圣题**：万圣节前夜、Trick or treat、南瓜灯最早的材料、萨温节。
- **煤球 · 两扇窗**：左右各十六格，右边有四处不同——少一只蝙蝠、蜡烛灭了、多一只蜘蛛、月亮圆了。
- **老瓤 · 南瓜秤**：三杆秤，按「南瓜 = 苹果、苹果 = 糖」的关系称出答案；`−` / `＋` 调整糖数，再点「称一称」。
- **德古 · 三只箱子**：每轮只有一句箱子上写的是真话。先找出互相矛盾的两句，第三句就一定是假的。

谜题没有失败，也没有倒计时（狼人的月亮除外）；答错只记次数。面板随时可以关掉，进度留在门上，下次敲门点「继续解谜」接着答。完成一扇门，这一户的固定糖直接进糖袋。

**后巷竞速：抢了就跑**

选「捣蛋」不再当场发糖，而是立刻切进一张独立的小地图「糖纸街后巷」。这一户的人追出来，你要跑到街尾的栅门；追上了糖就被拿回去。

- **规则**：拿到的永远是这一户原本那颗糖，不抽奖、不换成别的糖。跑到栅门 = 糖进糖袋，这一户记作「捣过蛋」；被追上 = 糖被拿回去，这一户保持原样，可以再敲门重试。半路按 `E` 摸一下起点的后门，可以主动掉头回街上，不拿糖。追兵是一整面糖纸浪，站在屋顶也躲不掉——只看前后距离，不看高度。
- **速度**：竞速里玩家移动是平时的 1.3 倍（被追的人跑得更快）。追兵从身后约 10 格开始，前 0.9 秒不动，之后按距离调整：甩得太远会加速追到约 8 格内，快到 3 格内会稍微收力。它不是固定速度的墙，但也不会凭空消失。
- **HUD**：左上角任务条显示「甩开 N 格」，条越满越安全；低于 6 格会提示一次，低于 3 格时屏幕边框转红。追兵在画面外时，左缘有三枚向后的箭头。
- **赛道**：168 格宽，栅门在 160 格。地面全程连续，没有即死缺口；掉进巷子只是丢时间。木箱都只有一到两格高，普通跳能过。三段屋顶是可选的快线：没有木箱和南瓜，但断口要跳准，落下就回到巷子重跑。三块糖浆加速带在 40、96、152 格附近，踩上去会往前冲一小段。
- **分段**：0–12 后门起跑 → 12–34 晾衣绳巷（第一段屋顶 / 巷子分岔）→ 34–52 晒糖场（长直道与第一块糖浆）→ 52–88 屋顶与巷子（三截屋顶、两处断口）→ 88–112 糖浆滑道（第二块糖浆与下沉巷底）→ 112–140 后段屋顶（更长的断口）→ 140–160 最后直道（两道矮箱，栅门的光柱已经看得见）。第一次跑到分岔、糖浆和最后直道时，各有一句路况提示。
- **存档**：竞速中途退出只记「被哪一户追」，读档或按 `R` 都从起跑线重新摆赛道，追兵回到起点。

竞速的数值在 `src/trickOrTreat.js` 的 `TRICK_RACE` 里调：玩家倍速、追兵速度与追赶曲线、起跑距离、警告阈值、赛道长度。赛道本身在 `src/level.js` 的 `buildTrickRace()`；追兵和糖纸浪的绘制在 `src/renderer.js` 的 `drawTrickRace()`。

**糖袋**

- 按 `Q`（或手机底部的「糖袋」）打开。糖袋是背包里单独的一层，不占骨槽和衣橱的格子；在任何线路都能打开：教程、给老师送南瓜派全线（含第三段潜行）、魑魅魍魉都可以。
- 在面板里点「吃一颗」或按数字键 `1`–`0`。吃下后回到路上，效果走的是和普通糖果相同的一套计时与叠加规则：同种糖延长持续时间，不同糖同时生效。
- 魑魅魍魉里整支队伍一起吃到效果；第三段里你和回音一起吃到效果；其它线路只有主角。
- 糖袋存在浏览器 localStorage（`pumpkin-hollow.candy-pouch.v1`）。清除游戏存档不会清空糖袋。

叠加规则：

- 不同糖果可以同时生效，数值按乘法叠加，行为各自触发；角色身上会同时出现几圈不同颜色的光。
- 同一种糖果再吃一颗，持续时间累加（上限为单颗时长的 2 倍）。
- 终点岛上的巧克力和甘草糖离得很近，可以连着吃下，观察两种状态叠加；第一口和第二口井里也各藏了一颗糖。
- Tab 背包里，糖果种类图鉴放在最下方，排在衣橱之后。

## 第三段 · 另一双脚步：双人同屏潜行

这一段不再单独成线：它缩进「给老师送南瓜派」，成为四段夜路里的第三段。原来的南瓜大宅、晾糖场、画像长廊和屋顶烟花都撤掉了，场景换回墓园外墙；两名玩家分别操控「你」和「回音」，在提灯人的灯光之间走到墓园门口。

### 故事

第三段路，你想起阿遥。她在山上守一台老无线电，能听见很远的声音，也听见一些别人听不见的。这一小段里，你身边多了一个只有你听得见的自己——回音。回音不是敌人，也不是帮手：它就是另一个你，会和你一起躲灯、一起压石板、一起走到门口。所以它长得和你一模一样：同一顶尖帽、同一个南瓜头、同一盏提灯，只是整个人是半透明的，头顶的光也淡一点。唯一不同的是鞋——皮鞋只有一双，穿在你脚上。

### 操作

| 玩家 | 移动 | 跳 | 潜行 | 互动（抱 / 抛南瓜） | 影子线 |
| --- | --- | --- | --- | --- | --- |
| 你 | `A` / `D` | `W` | 按住 `S` | `E` | 谁都能按 `Space` |
| 回音 | `←` / `→` | `↑` | 按住 `↓` | `/` | 谁都能按 `Space` |

- 两个人都走到墓园门口才算过关；任何一个人被提灯人照到，两个人会一起退回上一个「影子记号」。
- 按住潜行键会走得很慢，但身体变淡、灯几乎照不到；墓碑与围墙下的影子区则完全安全。
- 手机端没有第二套方向键：回音会自动跟着你走，一个人也能走完；压石板可以靠南瓜。
- 第三段没有背包，糖袋按 `Q` 仍可用。

### 机关

- **提灯人的灯**：提灯人提着灯在墓碑之间来回走，走到头就转身。灯锥跟着转，院子里的影子一段一段地换位置；等他背过去，或蹲低屏住呼吸。
- **石板门**：站上石板就能压开对应的铁门。门需要两块石板「同时」有人时，南瓜也能当砝码：推一颗到石板上，门会一直认它的重量。也有几扇门顶上留了缝：踩着南瓜或叠罗汉翻过去，再用影子线把同伴拉过来。
- **影子桥**：桥只在有人（或一颗南瓜）压住石板时存在。压住的人一松脚，桥就散；一个人压住，另一个人先过，过去的人再压住另一头。
- **叠罗汉与影子线**：跳到对方头顶就会站住；下面的人蹲下，上面的人再跳，会弹得更高。按住 `Space` 绷紧影子线，站稳的人当桩，把对方慢慢拉过来；吊在黑水沟上方时，线也能把人吊住。
- **南瓜**：路上能推、抱、抛、叠；两个人都能碰，但互动键分开——你按 `E`、回音按 `/`，谁按的谁动手。

### 看得见的配合

这一段沿用一套统一的颜色和连线：你青蓝、回音暖黄、南瓜橙、安全的影子薄荷色。这套颜色说的是「谁在起作用」，不是两个人的长相——两个人是同一副身体，回音只是半透明。石板和门之间有一条压线，谁压住石板，线就亮成他的颜色；门上的小符一一对应石板，踩住哪块就亮哪枚；被灯看到时，从灯口到人连出一条断续的红线，头顶同时冒一个越来越红的感叹号；藏进影子时，四周出现薄荷色括角；门边有两枚小灯位，谁到门口，属于他的那盏就亮。

这一段只有一张地图：从墓园外墙的缺口走到墓园门口，中间一条黑水沟靠影子桥过去。三个影子记号，被发现或掉进沟里都只退回上一个记号。结算会记下整条追思路线的时间、点亮的灯和皮鞋的合脚度；第三段自己的被发现 / 失足次数留在这一段的面板里。

## HUD 与可视化

- 靠近电子时，静态 HUD 显示「合力」箭头；它由所有电子按矢量叠加，正电荷被电子吸引，负电荷被电子排斥。
- 场区 HUD 显示 E / B 的大小与方向、当前场力的竖直方向、平衡速度、当前速度（带正负方向）与左右推进提示。
- 速度选择器的匀强电场以**长线 + 箭头**绘制，箭头沿 E 的方向流动；孤立电子不画电场线，只用光晕和中央减号。
- 磁场以 `⊗ 纸内 / ⊙ 纸外` 的符号网格显示。
- 井顶尖刺与裂隙都有独立的危险提示；所有骨头共用同一种骨色，只有形状和名字不同。
- 所有非岩浆地面都铺着不能拾取的细小白骨，作为场景氛围；可拾取物会发光、漂浮，并在拾取时显示提示。骨头共用暖白色；时装零件按稀有度发光，常见偏淡紫、少见偏青蓝、稀有偏金橙；糖果按种类各自发光。具体种类靠形状和名字区分。被增益糖锁住的零件会亮成那种糖的颜色，并带一把小锁；吃到对应糖后锁会消失。
- 吃到糖果后，角色身上会出现对应颜色的光晕，面板里列出所有生效状态与剩余时间；同种糖叠加时时间会累积。
- 双相情感障碍会在状态条上标出当前是「高涨」还是「低落」；发作性睡病睡着时头顶会冒 Z；飞行妄想状态下按住 ↑ 可以直接升空。

## 关键可调参数

- `src/config.js`：重力、跳跃、移动速度等基础手感；`FIELD` 块里的像素/米换算、电荷加速度系数与介质阻力；`ELECTRON.maxAcceleration` 限制电子核心附近的强度。
- `src/level.js`：地图、场区高度（当前 552px）、E/B 数值、骨槽与拾取物；`getFieldAcceleration()` 是 `F = q(E + v × B)` 的唯一实现，`getElectronAcceleration()` 负责所有电子的矢量叠加。
- `src/player.js` 的 `updateHover()`：把洛伦兹力积分进玩家轨迹，并叠加介质阻力；`applyElectricForce()` 使用统一的电子场合力。
- `src/game.js` 的 `getFieldStatus()`：HUD 实时提示（场力方向也来自同一套洛伦兹力计算）；电子合力也在这里汇总给 HUD。
- 场区的 `e.mag / b.mag` 比值决定平衡速度。
- `src/candyEffects.js`：每种糖果的持续时间、移动/跳跃修正和自动行为触发间隔；`src/game.js` 的 `updateCandyTimers()` / `updateCandyActions()` 负责结算。
- `src/pumpkins.js`：南瓜的尺寸、重力、摩擦、抛起初速度（`PUMPKIN`）都在文件顶部；`resolvePlayer()` 负责推与踩踏，`findStackTarget()` 决定抛起时会不会对准另一颗南瓜叠上去，`pickPlayer()` 是没指定角色时的兜底（第三段里通常由 `game.interact(actor)` 直接指定你或回音）；掉出地图的南瓜会回到 `homeX/homeY`。`src/level.js` 会把 `decorations` 里所有 `type: 'pumpkin'` 的摆放点抽成 `pumpkinSpawns`，由 `src/game.js` 在每次 `loadTheme()` 时重建 `PumpkinWorld`；普通线路每帧传入 `game.members`，第三段在 `src/sneakMode.js` 的 `updateSneak()` 里传入你和回音。
- `src/parade.js`：魑魅魍魉的六段章节（`PARADE_CHAPTERS`）、三条赛道（`PARADE_TRACKS`：额外夜路格数、落脚点密度、水流倍率、走散规则）、每段的天色与开场白、开场就有的同行者（`party`）、新客人（`joins`），以及 `YOKAI` 图鉴里每个身体的 `traits` / `teamLabel` 和 `PARADE_COMBOS`。想改科学怪人的速度、床单幽灵的重力、沼泽怪的游泳强度、蝙蝠的二段跳、木乃伊的绷带兜底、狼人的双击冲刺、女巫的滑翔、黑猫的蹬墙，先动这里。
- `src/level.js` 的 `buildParadeOne()`～`buildParadeSix()`：六张基础地图的格子、裂石（`C`）、水域（`waterZones` 的 `currentX` / `surfaceCurrentX`）、气泡柱（`updrafts`）、瘴气、石鼓（`device.type: 'mask'` 的 `yokaiIds`）、落脚点与 `goalY`。`applyParadeTrack()` 会在 `PARADE_ANNEX_AT` 指定的平地上插入额外夜路；想调整三条赛道的长度，改 `PARADE_TRACKS[].annex` 与 `PARADE_ANNEX_AT` / `PARADE_GROUND_ROW`。`goalY` 是终点南瓜鸟居所在的高度，用来防止有人从下层走到门柱下方也被算作到门。
- `src/game.js` 的 `setupParadeParty()` / `addParadeMember()` 负责队伍建立与请人；`rebuildPartySupport()` 把同伴的本事分给全队，`getParadeSupports()` 给名册提供队伍支援列表；`isMemberAtGate()` / `paradeGateCount()` 是所有到门的判定；`updateParadeHazards()` 负责全员冲散、木乃伊的绷带兜底与困难赛道的送别；`openSacrifice()` / `chooseSacrifice()` 是困难赛道的名册减员；`registerCrackPush()` / `updateTeamSmash()` 负责科学怪人被留下后「全队一起顶裂石」的弱化版本；`advanceParade()` 负责段与段之间保留队伍、赛道与已留下的名字。多身体共用按键时，`Input.fork()` 会给每个同行者一份各自的「刚按下」事件，避免第一个人把跳跃键吃掉。
- `src/player.js` 的 `traits` 读取：`moveScale`、`jumpScale`、`gravityScale`、`maxFallScale`、`waterMoveScale`、`swim`、`extraJumps`、`glide`、`smash`；`teamSupport` 读取队伍支援（全队二段跳、滑翔、划水、提速、轻风、双击冲刺、空中冲刺、蹬墙跳、绷带兜底、九命绷带）。`getWaterAt()` 的水流、水面急流、划水与水面跃出，以及 `getUpdraftAt()` 的气泡托举都在 `update()` 里结算，入水/出水通过 `onWaterEnter` / `onWaterExit` 交给 `src/game.js` 生成水花和声音；`breakColumn()` 在 `moveHorizontal()` 里触发。
- `src/sneak.js`：第三段「另一双脚步」的名字、目标、故事，以及地图格、石板门（`mode: 'all' | 'any'`、`latch`、`climbable`）、影子桥、提灯人（`range`、`halfAngle`、`sweep`、`speed`，以及来回走用的 `patrol` / `patrolSpeed`）、影子区、地图高度（`height` / `groundRow`）与教学提示；手机端的 `mobileText` 也在这里。这一段只有一张地图，`SNEAK_STAGE.spec` 是唯一的数据源。`src/sneakLevel.js` 负责把这些数据变成实际地图；铁门上方一直顶到夜空的透明符障是 'g' 格，实心但不画门，开门时和门一起消失——`climbable: true` 的门不铺符障，顶上留一道缝。`src/game.js` 的 `buildMemorialSneak()` 再把阿遥的记忆、蜡烛和 `sneak: true` 标记接到这张图上。`src/sneakMode.js` 的 `updateExposure()` 决定暴露快慢，`watcherSees()` 决定灯能不能看见某个人，`updateWatchers()` 让巡逻的提灯人转身，`updateGates()` 负责石板门与影子桥（人和南瓜都能压住秤盘），`updateStack()` 负责踩在头顶上的叠罗汉与蓄力弹跳，`updateRope()` 负责影子线的收紧、吊住、把人拉上高台，以及隔着 `climbable` 的门把同伴拽过去。手机端由 `game.mobileAssist` 让回音复制主角的输入。
- `src/memorial.js`：四段追思路线的诊断、记忆台词、连续修正、背景病色（`backdrop`）与触发间隔；第一段的南瓜车检查（`trigger.kind: 'carriage'`）也在这里调任务文本、5 秒频率和 10 秒倒计时。第一段开场的南瓜车独白在 `opening` 里：`driveTime` 是驶入用掉的时间，`alightAt` / `total` 是下车与演出结束的时刻，`skipAfter` 之后才能按互动键跳过，`beats` 是每一句独白的出现时间和文本。第二段的惊恐参数在 `trigger` 里：`firstInterval` / `interval` 是发作间隔，`premonition` 是心跳预兆，`breaths` 是呼吸次数（第二段现在是 1，按一下或按住 `E` 就够）、`beatPeriod` 是心跳/呼吸的节拍；`windowStart` / `windowEnd` 只给多拍呼吸的引导环用，`calm` 是定神期。第四段的 `solace.duration` 是旧灯透亮时间。`src/level.js` 的 `MEMORIAL_STAGE_SPECS` 是追思前两段的地图规格：第一段南瓜车与高墙，第二段两道集合门。第三段是双人潜行，由 `buildMemorialSneak()` 把 `src/sneak.js` 的地图接进追思路线；第四段的简易电磁赛道由 `buildMemorialElectromagnetic()` 单独建：四对铜球、四颗电子、四道五格裂隙（最后两条中间隔着一座小岛）和旧灯位置都在那里。`WITCH_SET_SPEC` 是糖纸街女巫房间的那一道门。`setGates` 用 `{ tile, expr, kind, tag, trayStart, trayWidth, trayGap, hint, success, elements: [{ tile, look, membership }] }` 摆放集合门：分格门的 `membership` 是内部归属（`a` / `b` / `both` / `none` / `notA`）；接龙门不写 `membership`，只写 `kind: 'mapping'`、`chain`（A 的接龙顺序）和 `shownLinks`（门楣先画前几段），地上的每颗 B 东西按接龙归到它前面那一样的小台，答案由 `mappingTargets()` 一次算出。`look` 决定它画成骷髅 / 幽灵 / 眼睛 / 蜡烛 / 手 / 骨头。`aMembers` / `bMembers` / `notAMembers` 由归属自动整理（接龙门为 `null`，门楣改成画接龙），成员板把图标放大两倍并写出名字。`buildTrickRoom('witch')` 用 `WITCH_SET_SPEC` 建那一道门，`buildTrickRoom('warlock')` 用 `buildMerged()` 建完整的电磁长夜。`src/setTheory.js` 的 `mappingTargets()` 把接龙顺序翻成「每颗 B 东西该去哪一个小台」，`correctTrayId()` 按归属算出每颗元素该去哪一格（接龙门查 `mappingTargets`），`trayAt()` 看它现在是不是真的踩在那格的地面上，`updateSetGates()` 在全部放对且玩家靠近时让石门开始下沉、沉完再撤碰撞；`src/setDraw.js` 负责地面分格、写着 A−B / A∩B / B−A / A∪B 加一横的标牌、接龙门的小台（A 图标 + 名字 + 向下箭头）、元素小精灵（放对了会亮）、门楣左侧放大图标并写名字的成员板、门脚进度和石门下沉动画。`src/game.js` 的 `updateMemorialTimers()` / `updateMemorialActions()` 负责定时行为，其中 `updatePanicState()` / `handlePanicPress()` / `finishPanic()` 管惊恐预兆、呼吸与定神，`applyMemorialWeight()` / `updateSlumpState()` / `updateMemorialSolaces()` 管第四段的负重、抬不起脚和旧灯透亮；`updateCarriageIntro()` / `updateCarriageTimers()` / `updateCarriageAlarm()` / `checkCarriage()` 负责第一段的下车演出、任务与抓狂，`advanceMemorial()` 负责门与门之间的推进。
- `src/trickPuzzles.js`：八户谜题的题面、选项、答案与解释。`skeleton` / `ghost` / `franken` / `pumpkinKing` / `vampire` 用 `rounds`；`mummy` 用 `pairs` 和 `icons`（翻牌牌组由 `createPuzzleState()` 洗牌）；`cat` 用两扇窗的 `left` / `right` 格子，`null` 是空格，`candleOut` / `moonFull` 是同一个图案的另一种画法，`spotDifferences()` 自动比较左右窗。面板交互在 `src/puzzleView.js` 的 `PuzzleView` 里；进度存在 `session.trickPuzzleStates`，随 `route.puzzles` 存档。想加一道题，先改这里的数据，再在 `trickOrTreat.js` 把那一户的 `task` 写成 `{ type: 'puzzle', puzzle: '<id>' }`。
- 狼人的追月：`src/trickOrTreat.js` 的 `task: { type: 'chase', marks: 5, timeLimit: 20 }`；`src/level.js` 的 `chasePlatforms` 是五级屋顶（每级抬高两格、横向隔两格、两格宽）；`src/game.js` 的 `updateChaseTask()` 判定顺序、掉回街面重置与 20 秒计时，`src/renderer.js` 的 `drawTrickTasks()` 画月牙记号、序号和虚线。
- 后巷竞速（抢了就跑）：参数都在 `src/trickOrTreat.js` 的 `TRICK_RACE`。`playerSpeedScale` 是玩家的 1.3 倍竞速速度，`boostScale` 是糖浆冲刺再叠的倍数；`startGap` / `grace` 是起跑距离与追兵起步前的空档；`chaserStartSpeed` / `chaserSpeedGain` 是追兵随赛程的基础速度；`chaseLeadTiles` / `catchUpPerTile` / `maxCatchUp` 是甩远后的追赶曲线，`mercyTiles` / `mercyScale` 是快贴上时的收力。`warnGapTiles` 控制提示，`dangerGapTiles` 控制屏幕红框。赛道格、木箱、屋顶断口、糖浆带和晾衣绳在 `src/level.js` 的 `buildTrickRace()`；追兵与浪的绘制在 `src/renderer.js` 的 `drawTrickRace()` / `drawCaramelZone()` / `drawRaceLaundry()`。
