# 给老师送南瓜派 · 游戏文案总表（审核用）

本文档收录**当前版本中玩家真正会看到的文字**，按玩家看到的顺序整理，方便逐条审核、改写。

## 使用说明

- 每条后面标注来源 `文件:行号`，改完可以直接定位。
- `${...}` 是运行时插入的值（段数、名字、秒数等），改写时保留；`\n` 表示换行。
- 收录范围：起始页、常驻界面、教程、主线四段、魑魅魍魉、糖纸街、谜题、道具说明、系统提示、结局。
- **不收录**：代码注释、控制台报错、`aria-label`（读屏用，界面不显示）、`<meta>` 描述、开发调试文字，以及当前版本未启用的旧糖果定义（见文末说明）。
- 同一句话在多处出现时，可能只挑一处列出；改动时建议用编辑器全局查找。
- 英文小标题（如 `Sir Loved Pumpkin Pie · 万圣夜`）也一并列出，请决定是否保留。
- ⚠️ 改名残留：页面标题已经是「给老师送南瓜派 / Sir Loved Pumpkin Pie」，但教程开场（「欢迎来到南瓜小径」）和提示面板兜底标题（「南瓜小径」）里仍写着旧名，审核时可一并决定。
